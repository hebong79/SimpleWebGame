# G028-15 · 햇빛과 바다 4목 제작설계

공통 계약 `../20261031-235605_G028_PM_CONTRACT.md`가 함께 적용됩니다. 로컬2인 기본판만 포함하며 선택사항인3판2선승·연습도움 강조는 제외합니다.

- 6행×7열, null/`sun`/`sea`, 첫판 선공 sun. 결과의 다음판은 직전 선공 교대. 진행중 재시작은 해당판 선공 유지. 단일 세션 승수 및 영구 sunWins/seaWins/draws 표시; 포기는 별도 결과로 정산하지 않음.
- 열을 고르면 가장 아래 빈칸에 원반 정확히1개. 가득찬열·범위밖·비정수·dropping/paused/result 입력은 상태/차례/시간/기록 no-op. 수당 원반종류/행/열/직전착수 보존.
- 유효착수 즉시 보드 한칸을 원자적으로 확정하고 `dropping` 200ms 논리잠금. 현재차례 표시는 착수자. 입력 추가는 큐에 넣지 않음. 200ms가 끝난 엔진 tick에서 마지막착수 기반 가로/세로/양대각 최대연속선을 검사. 4이상은승리(5이상포함), 승리우선→42칸가득이면무승부→아니면차례교대. reduced-motion에서도 논리200ms 유지.
- 승리선은 실제 연결된 모든칸을 보여주며 한 착수에서 여러선이면 전부 표시. 가장자리·음기울기·양기울기·긴선 검사. 비정상 외부 state 입력에 대한 공개함수 가드도 갖춤.
- 정지 중 dropping 남은시간과 보드 고정, 재개후 남은시간으로1회판정. 도움말/확인 모달이 결과를 정산하거나 보드를 바꾸지 않음. 결과에는 승자/무승부·이번 착수수·세션전적·누적전적·다음판/홈 제공.
- 7개 열 버튼은 aria-label `N열에 놓기`, 열번호와 채움/가득참을 텍스트 설명. 열 전체를 탭해 같은 열선택으로 처리. 가득차도 선택/초점은 가능하며 착수만 no-op. 좌우/Home/End는열 roving focus, Enter/Space native버튼착수. 화살표 자체는착수하지 않음. 마지막열에서우측은그대로, 자동wrap없음.
- 영구 schema: `{version:1,settings:{theme:'coast'|'evening',muted:boolean},records:{sunWins,seaWins,draws}}`. 세션전적은 메모리만. 세카운터 정수0..1e6 및합<=1e6; 관계손상시 records만초기화. 설정필드별복구. 결과한번에1승 또는1무만증가.
- 순수 규칙엔진(시간delta 주입)·저장모듈·DOM입력/뷰·오디오 분리. 원본 직접제작 CSS/SVG 원반/보드/테마 및 합성 착지/승리음. 소스/자체시험/수용보고는 BUILD15 소유.
