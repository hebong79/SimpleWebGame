## 발견과 보정

- 첫 엔진 실행의 L자 거절 fixture가 실제로는 같은 열이었던 좌표를 고쳤습니다. 구현 규칙을 완화하지 않았습니다.

- WebKit strict CSP에서 native `<select>` 생성만으로 UA 내부 스타일 차단 오류가 나는 것을 최소 DOM 재현으로 확인했습니다. 문제 선택을 44px 이전/다음 native 버튼으로 바꿨습니다. 동적 보드 크기/울타리 좌표도 정적 CSS 클래스로 바꿨습니다. CSP를 완화하거나 오류를 필터링하지 않았습니다.
- 면적 4의 연결 구역에서 단서 4는 고립 칸을 뜻하므로 합법 출제할 수 없습니다. 첫 문제는 가능한 높은 단서 3을 풍부하게 보이고 후반은 희소 단서로 구성했습니다.
