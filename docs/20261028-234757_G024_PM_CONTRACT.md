## 09 — 병아리의 소풍 / Chick Picnic

- New catalog ID `chick-picnic`; URL `/games/09-crossy/index.html`.
- 9 columns, 40 logical px per cell (world width 360). Start with two safe rows. Endless road/grass lanes, never more than 3 consecutive roads. No water, trains, 3D, coins, shop, or imported game art.
- Arrow keys while focused: one hop per fresh nonmodifier press; ignore repeat. Mobile arena tap moves forward; left/right/down swipe (>=24 CSS px, dominant axis, ties ignored) moves accordingly; optional 44px directional buttons provide accessible equivalent controls. One 120ms hop; while hopping reserve at most ONE next valid input, ignore further inputs. Validate bounds before reserving; invalid/no-op consumes no RNG, score, or cooldown.
- World positions interpolate during hop; collision is tested during motion, not only at destination. Fixed timestep <=1/120s and swept relative overlap (or an equivalently proven no-tunneling method) for cars/player. Use a fixed 28x28 logical body, excluding cosmetics; car collision geometry documented independently of art. Boundary contact counts as collision. Loss takes precedence over awarding progress on the same tick.
- Each road has one travel direction. Initial lane speed in [80,140] logical px/s; +10 per 20 highest rows, capped at 180. Vehicle-to-vehicle empty gap >=120px, including wrap/seam and future capped speeds. Deterministic injectable RNG for pure engine tests. Do not make an impossible fully blocked lane.
- Score is the highest newly reached forward row relative to starting row, one point per row, never farmed by backtracking. New maximum resets idle age. At 8 seconds without a new maximum show a clear 2-second warning; at 10 seconds settle idle loss once. Pause/dialog/blur/hidden tab/long-frame protection stops game time, cars, hops, reserved input, sound. Explicit resume required. Runtime RAF and inputs use monotonic callback arrival time, not stale RAF timestamps; >=250ms stalls protect-pause without advancing a tick.
- Flow: ready/start -> playing -> pause -> explicit resume; restart confirmation preserves old state on cancel; confirmed active restart/quit settles current result once; result retry starts ready/new round without repeat settlement. Home during active play uses confirmation/result before navigation. Reload creates a new ready game and retains only valid records/settings/cosmetics.
- Record format version 1, private key (document literal). Completed rounds only: plays, bestRows, totalRows; quit counts a completed round. Safe-integer nonnegative constraints; plays=0 iff all totals zero, bestRows<=totalRows<=plays*bestRows using BigInt, bestRows attainable by at least one round, zero-score rounds allowed. Reject impossible records. No automatic persistent write on load/recovery or midround. Storage getter/getItem/setItem failures retain memory play + visible persistent warning. Never delete any key.
- Cosmetics: basic body always; straw set free, firefighter set at totalRows>=300, frog raincoat at bestRows>=50. Each has hat/top/backpack. Preview full set and independently mixed owned parts, apply exactly once; cancel changes nothing. Locked preview allowed but apply impossible. Include 4 directions, hop/land/fail preview poses; same exact gameplay under every cosmetic. Original vector/CSS or Canvas art, no external fetch/fonts/images. Move/collision synthetic audio, default muted, failures degrade safely.
