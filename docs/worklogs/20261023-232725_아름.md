# G-012 · 새 시안 브라우저 열기 완료

- 날짜: 2026-10-23 (Asia/Seoul)
- 프로젝트: SimpleGames 01-2048
- 접속 주소: http://127.0.0.1:3102/

## 작업 내용
- 새 홈 시안을 HTTP 주소로 열 수 있도록 로컬 전용 미리보기 서버를 추가하고 실행했습니다.
- 기본 브라우저에 위 주소를 여는 명령을 실행했습니다. Codex 브라우저 패널에도 열기를 요청했습니다.
- `scripts/preview_prototype.mjs`, `package.json`의 `preview` 명령을 추가했습니다.
- 기존 정적 파일 처리기를 재사용해 시안 폴더와 필요한 이미지 자산만 제공합니다. 기존 3101 게임 서버는 변경하지 않았습니다.

## 실행
프로젝트 루트에서 `npm run preview`를 실행한 뒤 위 주소를 엽니다. 현재 서버는 백그라운드 Node 프로세스 PID 4080으로 실행 중이며 127.0.0.1에만 바인딩했습니다. PC 재시작 후에는 명령을 다시 실행합니다. 포트 변경은 `npm run preview -- --port 3103`입니다.

## 실제 검증
- builder JavaScript 문법 검사 통과, PM 서버 코드·실파일 확인.
- PM이 홈·스타일·스크립트·게임 화면·SVG 자산 8경로 HTTP 200을 확인했습니다.
- PM과 독립 QA가 프로젝트 루트 파일 4경로 HTTP 404 및 POST HTTP 405를 확인했습니다.
- 독립 QA Chromium HTTP 조작: 홈 12카드 → 게임 16칸 → 일시정지·재개 → 종료 결과 → 홈 복귀 통과. 브라우저 오류와 자원 로딩 실패는 0건입니다.
- 기본 브라우저 실행 요청 명령은 정상 종료했습니다. 실제 기본 브라우저 창의 화면은 별도로 관찰하지 않았습니다. Codex 패널 열기 결과는 queued입니다.

## 제한 및 다음 작업
현재 주소는 이 컴퓨터에서만 접속하는 시안 미리보기입니다. 실제 게임 통합이나 공개 배포는 하지 않았습니다. 게임 전체 테스트·엔진 빌드·물리 모바일기기 검증은 이번에 실행하지 않았습니다. 차단 사항은 없습니다. 다음 작업은 브라우저에서 시안을 검토하고 필요하면 실제 게임 통합을 진행하는 것입니다.
