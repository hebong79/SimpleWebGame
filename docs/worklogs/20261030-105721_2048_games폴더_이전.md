# 2048(숫자 정원)을 public/games/01-2048로 이전

- 기준 시각: 2026-10-30 10:57 KST. 사용자 요청: 2048도 `public/games` 폴더로 이전. 확인 후 범위는 "TS 소스까지 전부 이전", 기존 `/game.html`은 "새 주소로 교체"로 결정.

## 작업 내용

- `git mv`로 이동(이력 보존):
  - `src/client/{engine,state,input,storage,audio,main}.ts` → `public/games/01-2048/`
  - `public/game.html` → `public/games/01-2048/index.html`
  - `public/style.css` → `public/games/01-2048/styles.css` (다른 게임과 같은 이름)
- `index.html`: CSS/JS 참조를 `./styles.css`, `./main.js`로 변경. 파비콘·정원 그림은 공용 `/assets/`를 그대로 사용.
- 새 주소는 `/games/01-2048/index.html`(다른 게임과 같은 규칙). `/game.html`은 폐기했고 404가 됩니다.
- `tsconfig.json`: `public/games/01-2048/**/*.ts`를 컴파일 대상에 추가.
- `scripts/build.mjs`: `public`을 복사할 때 `.ts` 소스는 제외(컴파일된 `.js`만 배포 트리에 남김). 홈 스크립트 `library.ts`는 `src/client`에 남아 `/scripts/library.js`로 계속 배포됩니다.
- 링크 수정: `src/client/library.ts` 홈 카드 href, `public/index.html` noscript 링크, `README.md` 표.
- 테스트·스크립트 경로 수정: `tests/unit/*.test.ts` import 4개, e2e 스펙 7개(주소·정규식·모듈 경로·스타일시트 경로), `security-audit.mjs`(검사 대상 디렉터리에 새 폴더 추가), `scripts/package_release.py`(필수 파일 경로).

## 실제 검증

- `npx tsc --noEmit` 오류 없음. 깨끗한 빌드 디렉터리(`artifacts/`에 임시 생성 후 삭제)에서 `public/` 아래 `.ts` 누출 없음, `public/scripts/`에는 `library.js`만 남음.
- 단위 테스트 48개 통과. `tests/games` 468개 통과, `tests/launch-local.test.mjs` 29개 통과.
- 실제 HTTP: `/games/01-2048/{index.html,main.js,state.js,styles.css}` 200과 올바른 MIME, `/game.html`·`/style.css`·`main.ts` 404.
- Playwright(desktop-chromium + mobile-webkit) `hybrid-input`, `library-integration`, `independent-qa`, `multi-game-integration` 62개 통과. 첫 실행에서 URL 정규식 `/\/game\.html$/` 3곳을 놓쳐 6개가 실패했고, 수정 후 모두 통과했습니다.
- `security-audit.mjs`: 요청 16건, unsafeSinks 0, pass.

## 제한 사항

- **운영 미반영**: 3116 서버(PM2 `number-garden-2048`)는 `artifacts/g025-build`를 실행 중이라 이번 변경이 반영되지 않았습니다. 반영하려면 새 빌드와 재기동 승인이 필요하며, 반영 후에는 기존 `http://192.168.0.195:3116/game.html` 즐겨찾기가 404가 됩니다.
- 타일·정원 SVG(`public/assets/tiles`, `gardens`)는 이동하지 않았습니다. 에셋 생성기(`assets/generate_assets.py`)가 `public/assets` 아래 15개 파일의 정확한 경로를 검증하고, 홈 화면(`home.css`)도 `gardens/grove.svg`를 쓰기 때문입니다.
- 실행하지 않은 검증: `npm test` 전체, mobile-chromium 프로젝트, `g024`/`g025`/`live-server` 스펙(3116 대상). `g025` 스펙은 경로 문자열만 수정했고 실행하지 않았습니다.
- `dist/`(gitignore)에는 이전 빌드의 `style.css`, `scripts/main.js` 등이 남아 있습니다. 삭제하지 않았으며 검증은 깨끗한 디렉터리에서 했습니다.
- `scripts/g025-verify.mjs`의 매니페스트 SHA는 일치하지 않을 수 있습니다. 커밋은 하지 않았습니다.
