# docs 폴더 md 파일명 `YYYYmmDD-HHMMss_이름.md` 형식 정리

- 기준 시각: 2026-10-30 08:39 KST. 사용자 요청: docs 폴더의 md 파일명을 시각 접두사 형식으로 바꾸고, 연관된 참조도 함께 수정.
- 범위(사용자 선택): docs 루트+하위폴더 md 92개는 새 형식으로, worklogs의 `_아름` 26개는 시각을 유지한 채 자리표시자만 실제 작업명으로 교체. 참조는 살아있는 코드·문서만 수정.

## 작업 내용

- 접두사 시각: 추적 파일은 `git log --follow --diff-filter=A`의 최초 커밋 시각(KST), 미추적 4개(CODY01_AUTO_REVIEW, G022_DEPLOYMENT, G023_RELEASE_RESTORE, G023_WORKER_CONTRACTS)는 파일 수정 시각.
- 이름 변경 118개(92 + 26). 본문 이름은 기존 대문자 이름 그대로 유지(예: `20261024-231330_GAME_DESIGN.md`, 이후 init-design 폴더로 이동). 하위폴더 README/REVIEW도 같은 형식(`docs/g018-design/…_README.md`).
- 참조 치환 90개 파일, 318곳: AGENTS.md, README.md, `.game-team/project.json`·`TEAM.md`, `scripts/g025-verify.mjs`·`package_release.py`, `tests/e2e/*`(문서 비노출 404 검사 경로), `assets/*`, `team/reports/DEV-01.md`, docs 내부 md 상호링크·worklog 경로.
- 변경 방식: 경로 전체(`docs/…`, 역슬래시 포함)와 단독 파일명(`GAME_DESIGN.md`)을 매핑표로 일괄 치환. `README.md`·`REVIEW.md`처럼 중복되는 단독 이름은 치환하지 않음. 스테이징·커밋은 하지 않음.

## 실제 검증

- docs 내 모든 `.md`가 `YYYYmmDD-HHMMss_` 접두사 형식인지 파일 목록으로 확인(예외 0), `아름` 파일명 0개.
- 치환 재실행 드라이런: 남은 옛 이름 참조 0건.
- 살아있는 파일의 `docs/…md` 참조가 실제 파일을 가리키는지 전수 확인: 끊어진 링크는 과거 기록 안의 자리표시자/약식 표기 4건뿐(`yyyyMMdd-HHmmSS_아름.md`, `실제한국시각_아름.md`, `G018_05/06_IMPLEMENTATION.md`).
- `node --check`(g025-verify.mjs, security-audit.mjs), `py_compile`(package_release.py, generate_assets.py) 통과.
- 게임 단위/브라우저 테스트와 3116 서버 확인은 이번 작업에서 실행하지 않았습니다(문서·경로 문자열만 변경, 서버 소스는 미변경).

## 제한 사항

- 과거 증거 파일은 의도적으로 수정하지 않았습니다: `docs/*.json`, `artifacts/`, `workers/*/verification/`, `.game-team/verification/`, `releases/*.zip`, `dist/`. 이 안의 옛 경로는 당시 기록 그대로입니다.
- **G025 재검증 주의**: `scripts/g025-verify.mjs`의 `assertReady`는 `artifacts/g025-build/g025-build-manifest.json`의 source SHA와 현재 파일을 비교합니다. `scripts/`·`tests/`·G025 문서 경로가 바뀌어 지금 실행하면 `build/source SHA mismatch`가 날 수 있습니다(실행해 확인하지는 않았음). 3116 서버는 이 매니페스트를 쓰지 않아 실행에는 영향이 없다고 판단하지만 서버 재기동으로 확인하지는 않았습니다. 재검증이 필요하면 새 빌드/매니페스트 재생성이 필요하며 별도 승인 작업입니다.
- git은 개명을 "삭제 + 미추적"으로 표시합니다. `git add -A docs`로 스테이징하면 rename으로 인식됩니다.
- 이후 새 문서는 `docs/YYYYmmDD-HHMMss_이름.md` 형식으로 만들어야 하며, 과거 문서를 이름만으로 찾던 도구·습관은 새 이름을 써야 합니다.
