## 범위와 남은 사항

- **이 구성은 프로젝트 실행기와 VS Code Tasks 연동입니다. Codex 확장의 채팅 목록에 자동 등록한 것이 아닙니다.** 사용자는 상태·로그·변경 코드·결과를 VS Code에서 확인합니다. 관찰 목적으로 전용 세션을 다른 앱에서 동시에 열면 writer 충돌이 날 수 있습니다.
- 워커는 요청할 때 실행되고 종료하는 on-demand 방식입니다. 상주 서비스·자동 시작·자동 재시도는 추가하지 않았습니다. 현재 `succeeded`는 마지막 요청 성공을 뜻하며 다음 PM 지시를 받을 준비가 된 상태입니다.
- 실제 게임 수정 업무는 아직 배정하지 않았습니다. 파일별 허용 범위는 PM 운영 규칙이며 모든 접근을 막는 OS 격리 보장은 아닙니다. 기본 read-only 검증과 별개로 실제 workspace-write 업무는 다음 승인된 작업에서 검증합니다.
- GUI 메뉴 클릭, 실제 Windows 프로세스 트리 종료 경로는 별도 실측하지 않았습니다. 해당 종료 로직은 단위 mock 검증 범위입니다. 게임 전체 테스트·빌드·플레이는 이번 설정 작업에서 재실행하지 않았습니다.
- 실제 비밀값은 테스트에 사용하지 않았습니다. 인증정보를 문서나 프로젝트로 복사하지 않았으며 로그 마스킹은 모든 형태의 비밀을 보장하는 DLP 제품이 아닙니다. 비밀값을 요청문에 넣지 않습니다.
