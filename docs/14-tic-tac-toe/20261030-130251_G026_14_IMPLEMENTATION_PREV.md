## 실제 export API (Node import로 조회 확인)

`engine.mjs`:
- 상수 `COUNTER_CAP=1000000`, frozen `WINNING_LINES`.
- `createGame()`, `startGame(state)`, `place(state, index)`, `pauseGame(state, cause='manual')`, `resumeGame(state)`, `nextRound(state)`, `restartRound(state)`.
- `rove(index, key)`, `opposite(player)`, `emptyTotals()`, `incrementTotals(totals, outcome)`, `totalRounds(totals)` (BigInt 반환).
- 엔진 state: `{phase:'ready'|'playing'|'paused'|'result', pauseCause:null|'manual'|'dialog'|'protection', round, session}`.
- round: `{id,starter:'X'|'O',current:'X'|'O',board:Array<null|'X'|'O>(9),moves,winner:null|'X'|'O'|'draw',winningLines:number[][]}`. 결과 current는 마지막 착수자입니다. `id`는 모든 새 판에서 증가합니다. invalid 입력은 원래 state 객체를 반환합니다.

`save.mjs`:
- `STORAGE_KEY`, `THEMES`, `defaultRecord()`, `validTotals(value)`, `recoverRecord(value) -> {record,warnings}`.
- `loadRecord(getStorage?) -> {record,warnings}`; 기본 getter는 브라우저 localStorage입니다.
- `saveRecord(record,getStorage?) -> {ok,warning}`.
- `settleRecord(record,outcome) -> record`. 이것은 순수 누적 전적 갱신 API이며 매 호출 자체의 중복판 식별 기능은 없습니다. 실제 UI는 playing→result 단일 전이에서 한 번만 호출/저장합니다.

`audio.mjs`: `createSound() -> {play(kind,muted),stop()}` (`kind`: X/O/win/draw). main.mjs는 live state setter나 gameplay export를 제공하지 않습니다.

## 읽기 전용 관측 (실제 shape)

`window.__g026Snapshot()`은 매 호출 structuredClone을 반환합니다. 반환값을 수정해도 게임은 변하지 않습니다. 함수 property는 non-writable/non-configurable이며 **setter·autosolve·테스트 gameplay 분기 없음**.

```js
{
  gameId: 'star-moon',
  phase, pauseCause,
  round: { id, starter, current, board, moves, winner, winningLines },
  board, // round.board의 같은 내용; live 배열 아님
  stats: { session: {xWins,oWins,draws}, lifetime: {xWins,oWins,draws} },
  settings: {theme:'paper'|'night',muted:boolean},
  record: {version:1,settings,lifetime},
  timing: null, // 이 게임에는 시간 metric이 없음
  selection: 0..8,
  modal: null | {kind:'help'|'theme'|'home'|'restart',preview:'paper'|'night'},
  warnings: string[] // load/write의 지속 경고; cap 안내는 DOM에서 추가 계산
}
```

modal 동안 phase는 ready/result를 제외하면 `paused`이며 별도 `'dialog'` phase는 없습니다. preview는 `modal.preview`와 body data-theme에서 확인하며, settings.theme는 Apply 전까지 바뀌지 않습니다.

## 실제 공개 selector

| 대상 | selector / 관측 |
|---|---|
| 셀 | `#cell-0` … `#cell-8` (row-major), `.cell`, `[data-index]`, `aria-label='n행 n열, 빈칸/별 X/달 O[, 승리 줄]'` |
| 판/차례/메시지 | `#board`, `#turn`, `#state-message` (live status) |
| 흐름 | `#start`, `#pause`, `#resume`, `#next`, `#restart` (phase에 따라 hidden) |
| 메뉴 | `#home` href `/`, `#theme`, `#help`, `#mute` aria-pressed |
| 창 | `#modal`, `#modal-title`, `#modal-content`, `#modal-apply`, `#modal-close` |
| 테마 | `#theme-paper`, `#theme-night` role radio / aria-checked, radiogroup |
| 전적 | `#session-x`, `#session-draw`, `#session-o`, `#lifetime` |

셀은 occupied/locked/result에 `aria-disabled=true`이나 native focus/navigation을 위해 실제 disabled 속성은 쓰지 않습니다. 무효 입력을 검사할 때 Playwright locator actionability가 입력을 먼저 거부하므로, trusted 좌표 mouse down/up 또는 native 키보드를 사용하십시오. 유효 입력은 보통 locator.click/tap으로 검사 가능합니다.

## 저장 shape / 정산

키 `simplegames.star-moon.v1`:

```json
{"version":1,"settings":{"theme":"paper","muted":true},"lifetime":{"xWins":0,"oWins":0,"draws":0}}
```

- safe nonnegative integer 3개를 BigInt 합 검증하여 총 1,000,000 이하만 허용합니다. 세션과 누적 각각 cap에서 전체 증가를 멈추되 플레이는 계속합니다.
- lifetime 오류는 상호 관련된 세 필드 모두 0 복구, 정상 settings 보존. settings 오류는 필드별 기본값 복구. JSON/버전 오류는 본 게임 기본값+경고이며 자동 삭제/쓰기 없음.
- getter/getItem/setItem 예외 각각 처리. 저장 실패 시 메모리 전적과 지속 경고를 유지하며 저장 성공으로 표시하지 않습니다.
- 저장은 실제 결과 1회 또는 mute/테마 Apply에만 수행합니다. Ready/start/next/abandon/restart/pause/focus/preview/Cancel/no-op는 쓰지 않습니다. 다른 키는 건드리지 않습니다.
- reload: 준비 상태, 빈 보드, 선공 X, 세션 0. 누적/settings만 복원합니다.
