## 공통 흐름·입력·저장

- 준비→명시적 시작→플레이(게임별 하위 상태)→정지→결과. 도움말/테마/진행중 홈·재시작 확인은 먼저 정지시킨다. 취소/닫기는 정지로 복귀하고 자동재개하지 않는다. 모달 중 blur/hidden/pagehide는 모달 유지+보호정지 사유 우선. 보호정지 문구는 `게임 재개`, 수동만 `이어서하기`.
- 결과/준비 홈은 직접 이동. 진행중 홈은 포기 확인 후 이동하고 미완료판 기록을 정산하지 않는다. 새 판 확인 취소는 보드/타이밍/누적 그대로. 결과 재도전은 확인 없이 새판. 결과는 동기적으로 정확히1회 정산, 애니메이션 완료 콜백에 규칙을 맡기지 않는다.
- 게임 키는 보드/패드에 포커스가 있고 visible이며 playing일 때만. 버튼 Enter/Space native 활성화는 지원하되 repeat/누른키 유지 중 중복 실행 방지. Esc는 모달 닫기 또는 정지이며 확인을 실행하지 않는다. 게임 외부 방향키/숫자키는 소비하지 않는다.
- 실제80ms 이상 trusted 누름이 RAF DOM갱신 때문에 사라지지 않게 한다. 같은 값의 textContent/자식/속성을 프레임마다 교체하지 않는다. 단일 포인터 down/up 같은 대상·이동<=8px만 탭, 스크롤/취소/lost capture/두번째 포인터(보드 밖 포함)는 취소. 취소뒤 synthetic click 억제, native 키보드 click은 유지. 상태 전환에서 입력잔상 초기화.
- 정지/모달/hidden 중 시간·타이머·오디오·예약 상태가 진행되지 않는다. RAF 단조 delta 및 clock을 명시; 긴 프레임(>250ms)은 보호정지하여 스케줄러 정지로 게임이 끝나지 않게 한다. stale callback은 round token으로 차단. 재개는 남은 논리시간을 이어간다.
- 키 `simplegames.sun-sea-four.v1` / `simplegames.four-star-song.v1`, version1. 설정과 완료기록만 저장, 보드/미완료순서 저장 금지. getItem/getter/setItem 예외 모두 메모리 플레이+지속 경고, 타키 보존. JSON/버전/primitive/finite safe integer/범위/관계 검사. 한 설정이 손상돼도 유효한 기록은 보존하며 불량 레코드만 복구.
- 읽기/초기화/정지/재개/미리보기/취소/no-op에는 쓰지 않는다. 결과 최초1회, 설정 적용/음소거 명시변경에만 쓴다. 누적카운터 합계 최대1,000,000, 상한에서 결과 항목을 부분 증가시키지 않는다.
- WebAudio 사용자 제스처 후 활성화; 미지원/생성·resume실패는 무음 진행. 정지/숨김에서 음 정지. 합성음·CSS/SVG는 직접 제작해 구현보고에 원출처/라이선스(외부저작물 미사용)를 기록한다. CSP 완화·외부 CDN·원격 폰트·새 패키지·유료자산 없음.
- 검사 API `window.__g028Snapshot()`는 deep clone 읽기 전용 데이터(phase, subphase, round, 보드/순서, 남은시간, 기록, 설정). setter·정답입력·자동승리·테스트전용 게임분기 금지. pure engine/save exports 및 실제 DOM selector는 구현보고에 기록.
