## 변경 내용 (최소 변경)
### D1 (높음) WebKit에서 초점된 칸의 탭 무시 — `public/games/17-flip/main.mjs`
- 원인: 칸 click 핸들러가 `document.activeElement !== b`이면 무조건 반환. WebKit은 버튼 클릭 시 초점을 주지 않고 초점된 버튼을 누르면 blur합니다.
- 수정: 무조건 초점 가드를 제거하고 `e.detail === 0 && document.activeElement !== b`일 때만 반환합니다.
  - 포인터 클릭(`detail > 0`)은 이미 capture 단계의 제스처 검증(8px 이동·scroll·두 번째 포인터·합성 click 억제)을 통과한 것만 도달하므로 별도 초점 조건이 필요 없습니다.
  - 키보드가 만든 click(`detail === 0`)과 스크립트 `click()`은 해당 칸에 초점이 있어야만 처리합니다.
  - 칸이 초점을 갖지 않은 채 정상 포인터 탭이 들어오면 `selectCell(i)`로 그 칸에 초점·선택을 맞춘 뒤 판정합니다(이후 방향키 이어서 사용 가능, WebKit에서도 Chromium과 같은 선택 상태).
  - 유지: 모달 열림/`document.hidden`/비-playing 가드, Enter/Space 반복 방지(`held`/`e.repeat`), 포인터 취소 로직, 외부 키 소비 금지는 손대지 않았습니다.
