# G029 17 · 별빛 스위치 설계와 수용 기준

공통 계약 `../20261101-224000_G029_PM_CONTRACT.md`를 따른다. 1인 논리퍼즐, 목표30초~4분은 사람 체감 미검증 목표이며 제한시간 없음.

## 규칙·콘텐츠

- 1~5단계3×3, 6~15단계4×4. 셀1=켜짐,0=꺼짐. 선택 칸 및 상하좌우만 동시에 XOR, 보드 외 무시. 클릭1회=이동1, 같은 칸2회는 원상복구.
- 15개의 고정 스테이지를 직접 제작한다. 모든 칸이 켜진 판에서 서로 다른 위치의 고정 scramble 클릭을 적용해 만들고, scramble 재적용으로 성공 가능함을 검증한다. 빈/이미 완성 시작판 금지, 단계 간 중복판 금지.
- 목표는 정확 solver로 검증한 최소 클릭 수. 3×3은2^9,4×4는2^16 전체 press mask를 XOR 행렬에 적용해 최소 popcount를 구하면 충분하다. 원안대로 scramble 길이를 최소라고 추정하지 않는다. 단계 데이터에 size/scramble/target를 기록하고 단위테스트 oracle로 최적성 확인.
- 모든 칸이 켜진 즉시 결과를1회 정산. 별3개=이동<=target,2개=target+2 이하,나머지1개. 시간점수/실패 제한 없음. 미완료 포기는 결과로 저장하지 않는다.
- 되돌리기는 마지막 클릭과 이동 수를 되돌리고 기록/해금에 영향 없음. history 비어 있으면 no-op. 성공 후 undo 금지. 처음부터는 같은 단계의 같은 배치로 이동0/history0, 진행중 확인 필수.
- 단계1 기본 해금, 클리어 시 다음 단계 해금(최대15). 해금된 단계만 준비에서 선택. 결과 다음단계는 명시적으로 다음 새판 시작,15단계는 전체 완료 표시.
- stage bestMoves/min, bestStars/max, clearCount 및 전체 completed 수. 같은 결과 중복 쓰기/중복카운트 금지. 설정 theme/night|paper, muted boolean. 기록은 단계별 검증.
- 방향키는 칸 이동(경계 clamp), Enter/Space로1회 반전, 클릭/탭도 동일 규칙. 영향 preview는 포커스/hover로 갱신하고 모바일 첫 탭은 실제 클릭(18과 혼동 금지).
- 시각 반전 피드백은120ms 논리잠금, 정지 시 남은 시간 유지. 성공 판정은 클릭의 원자적 엔진 처리에서 확정하며 결과도 동일1회. 애니메이션 callback에 규칙 의존 금지.

## 수용표

1. 모서리3칸/변4칸/중앙5칸, 대각·줄넘김 없음, double toggle 동일판.
2. 15단계 크기/해결가능/중복없음/미완성 시작/target 최적·별경계 검증.
3. undo·새판취소·재도전·단계선택/잠금·마지막단계·완료중복 보호.
4. 실제HTTP의80ms trusted 클릭/탭·키 반복·스크롤취소·다중터치취소·보호정지·모달 focus.
5. 저장손상/차단/유효필드부분복구/다른키 보존/설정별 테마 기록불변.
6. PC 및320px·mobile Chromium/WebKit 레이아웃,44px 버튼·상태기호·콘솔/CSP/외부요청0.
