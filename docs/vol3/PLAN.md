## 공통 구현·검증 계약

1. 준비 화면에 목표와 첫 입력을 안내하고 시작·핵심 입력·승패/목표·재시작·홈 복귀까지 실제로 연결합니다. 퍼즐은 실행 취소, 액션은 정지/재개와 즉시 재도전, 대전은 재대결을 제공합니다.
2. 포인터·터치와 키보드를 모두 제공합니다. 게임 밖 포커스에서는 방향키/Space를 게임에 소비하지 않습니다. 키 반복·다중 포인터·취소·blur/visibility를 처리합니다. 액션 57~59의 좌우와 보조 행동은 모바일 동시 입력이 가능해야 합니다.
3. 320px 이상에서 가로 넘침 없이 표시합니다. 일반 조작은 44×44px 이상이며 촘촘한 보드에는 키보드 이동과 명확한 선택 표시를 제공합니다. 색상에는 기호/문양을 더합니다.
4. 실시간 시계는 탭 이탈·정지 중 동결하고 명시적으로 재개합니다. 정지·재시작 시 눌린 키/포인터가 남아 오작동하지 않아야 합니다. 프레임마다 같은 버튼 DOM을 교체하지 않습니다.
5. 기록·설정·해금·선택을 게임별 버전 있는 키에 저장하고 자료형·범위·잠금 조건을 검사합니다. 읽기 손상·쓰기 차단에서도 계속 플레이하며 저장 실패를 알려야 합니다. 외형은 충돌·규칙·점수·판정에 영향을 주지 않습니다.
6. 아래 최소 콘텐츠 수량은 원안의 첫 제작 범위입니다. 단일 문제를 회전/이름만 바꾸어 수량을 채우거나 핵심 규칙을 공통 타이머/클릭 점수로 대체하는 축소는 승인된 적이 없습니다. 수량/규칙 미충족은 한계 또는 미완료로 기록합니다.
7. 고정 퍼즐은 실제 해 존재 검증을 남깁니다. 유일해 전제 문제는 해 수를 2까지 세는 솔버 등으로 유일성을 검증합니다. 정답 배열과의 단순 일치만으로 규칙 판정을 대신하지 않습니다. 대칭 변형 문제는 동일 문제군임을 숨기지 않습니다.
8. 신규 그림은 직접 제작한 도형/SVG/CSS, 음향은 자체 합성을 사용하고 라이선스 장부에 남깁니다. 시안은 구현 참고이며 원작 그림·상표·소스는 복제하지 않습니다.
9. 자동 단위 검사, 빌드, 실제HTTP 브라우저 자동 조작, 화면 검토, 인간 수동 플레이·실물폰·청취를 구분합니다. PC Chromium·모바일 Chromium·모바일 WebKit에서 현실 시계 약80ms trusted 누름과 엄격 CSP 검사를 초기 smoke에 넣습니다.
10. 최종 통합과 상태 변경은 PM만 수행합니다. 홈 등록→새 후보 빌드→독립 QA→승인된 운영 전환→실제 15010의 카드 클릭/시작/입력/정지/재개/홈 및 HTTP 바이트·PM2 경로/PID/LISTEN 확인→일지·게시 readback 순서를 후속 의존성으로 남깁니다. 이 기획서는 배포 승인 문서가 아닙니다.
