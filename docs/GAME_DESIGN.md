### G-013 승인 변경 — 홈과 실제 게임 통합

사용자의 '시안대로 게임 제작' 승인으로 다음 항목을 제작 범위에 포함합니다. `/`와 `/index.html`은 작은 쉼표 게임 목록이며 `/game.html`은 실제 2048 플레이입니다. 홈의 검색·장르·즐겨찾기·상태 필터·정렬·12개씩 더보기를 구현합니다. 현재 플레이 가능한 게임은 숫자 정원 1개이며 나머지 29개는 개발 예정 구성입니다. 홈 개편은 추가 게임 29종의 구현 완료를 뜻하지 않습니다.

홈에서 게임을 선택하거나 게임 주소로 직접 진입하면 점수 0·타일 2개의 새 판을 한 번 시작합니다. 게임 페이지 새로고침도 새 판입니다. 홈 진입만으로 게임 판 수를 늘리지 않습니다. 일시정지 버튼으로 멈춘 창에만 '이어서하기'를 표시하며 Esc·탭/창 이탈에 따른 보호 정지는 '게임 재개'를 표시합니다. 재시작 취소는 기존 정지 상태와 원인을 보존합니다.

게임종료와 게임 내 홈 링크는 현재 점수·최고 타일·종료 사유를 보여주는 결과창을 먼저 엽니다. 결과의 홈으로에서 목록으로 이동하며 결과 재시작은 즉시 새 판을 시작합니다. 자발 종료는 막힘 종료 횟수로 집계하지 않습니다. 2048 달성 후 계속 도전과 동시 막힘 처리, 기록·정원·음소거·입력 안전은 기존 규칙을 유지합니다.

## 1. 경험 목표와 범위

숫자를 차분하게 합치고 개인 기록을 쌓으며 정원을 해금하는 게임입니다. 한 판의 목표 체험 길이는 3~10분이며 시간제한이나 강제 종료 시간은 없습니다. 성공 후에도 더 큰 수를 만들 수 있습니다.

### In scope — 첫 제작 필수

- 4×4 보드, 정확한 단일 합치기, 시작 타일 2개, 2/4 생성 확률 90:10, no-op 보호입니다.
- 현재점수·최고점·최고 타일·누적 기록, 128→256→512→1024→2048 목표 안내입니다.
- 게임 목록 홈과 선택 후 새 판 시작, 2048 최초 달성창과 계속 도전, 자연·자발 종료 결과, 일시정지/탭 이탈 보호입니다.
- 방향키/Esc, 모바일 24px 스와이프, 게임 포커스 제한, 최소 44×44px 버튼입니다.
- 재시작 확인, 도움말, 음소거 및 합치기 합성음, 정원 3종과 해금·선택·저장입니다.
- 320px 모바일부터 PC까지 반응형, 직접 제작 SVG 타일 11종·정원 3종·favicon입니다.
- 버전·유효성을 검사하는 localStorage, 손상 저장·저장 차단 복구, 외부 인터넷 없는 로컬 플레이입니다.

### Out of scope — 첫 제작 제외

- 온라인 계정·광고·결제·분석 전송·랭킹 서버·멀티플레이·외부 CDN·SQLite입니다.
- 다른 게임 29종의 실제 구현은 제외합니다. 게임 목록 홈은 G-013 승인으로 범위에 포함합니다.
- 캐릭터·부위별 코스튬·재화·상점·일일 보상·스테이지·보드 크기/난이도 변형입니다.
- 실행 취소·자동 플레이·힌트 해법·키 재설정·PWA·서비스워커·공개 배포입니다.
- 진행 중인 판의 reload/앱 종료 후 재개입니다. 판은 저장하지 않고 게임 페이지를 새로 열면 새 판을 시작합니다. 최고기록·누적기록·해금·선택·음소거는 유지합니다.

## 2. 규칙과 처리 순서

### 보드와 생성 [AC-R01~R05]

- `Board = number[][]`의 4행×4열입니다. 0은 빈칸이며 타일은 2 이상의 2의 거듭제곱입니다.
- 게임 페이지 진입 또는 새 판 확정 시 빈 보드의 서로 다른 빈칸 2곳에 순서대로 타일을 생성합니다. 시작한 판 수와 생성 직후 최고 타일도 같은 시작 처리에서 갱신·저장합니다. 홈 화면에서는 생성하지 않습니다.
- 매 생성마다 빈칸을 균등하게 하나 선택하고 독립적인 난수로 값 2(90%) 또는 4(10%)를 결정합니다. 값 판정 난수 `r`의 범위는 [0,1), `r < 0.9`는 2, 그 외는 4입니다.
- 방향은 `Direction = 'up' | 'down' | 'left' | 'right'`입니다. 각 행/열을 이동 방향의 앞쪽부터 읽어 0을 제거하고, 인접한 같은 값 한 쌍을 한 번만 합친 뒤 빈칸을 뒤에 채웁니다.
- 같은 입력에서 새로 합쳐진 타일은 다시 합쳐지지 않습니다. 왼쪽 예: `[2,2,2,2] → [4,4,0,0]`, `[2,2,4,0] → [4,4,0,0]`, `[4,4,4,0] → [8,4,0,0]`입니다. 이 예시는 새 타일 생성 전 결과입니다.
- 보드가 달라졌을 때만 이동을 1회 확정하고 새 타일 1개를 생성합니다. no-op은 보드·점수·난수 소비·이동 수·누적 기록·효과음을 전혀 바꾸지 않습니다.
- 빈칸이 있거나 상하좌우로 같은 값이 인접하면 이동 가능합니다. 대각선은 합칠 수 없습니다. 빈칸도 인접 쌍도 없으면 막힌 판입니다.
- 2048 후에도 같은 규칙으로 4096 이상을 허용합니다. 11종 아트를 넘는 값은 최상위 타일 외형에 실제 숫자 텍스트를 표시합니다. 숫자를 2048로 축약하지 않습니다.

### 점수·성공·종료 [AC-R06~R08]

- 합쳐진 결과값의 합만 현재점수에 더합니다. 2+2는 4점, 4+4는 8점이며 단순 이동·생성은 0점입니다.
- 유효 이동 한 번의 순서는 이동/합치기 → 점수 반영 → 타일 1개 생성 → 최고/누적 기록 및 해금 반영 → 2048 최초 도달과 막힘 판정 → 화면/저장 확정입니다. 애니메이션 종료 콜백이 규칙을 변경해서는 안 됩니다.
- 한 판에서 처음 2048 이상이 생기면 축하창을 한 번만 띄웁니다. 점수·개인 최고 여부·달성 타일, 계속하기, 재시작을 제공합니다. 다시 큰 타일을 만들어도 중복 보상/축하창이 없습니다.
- **2048 최초 달성과 막힘이 같은 이동에 발생하면 축하를 먼저 표시합니다.** 축하창에 “목표 달성 · 더 이상 이동할 수 없습니다”를 함께 표시하며 계속하기를 비활성화합니다. “결과 보기”로 막힘 결과를 엽니다. 이동 가능한 성공판에서는 계속하기가 플레이로 돌아갑니다.
- 막힘 결과는 해당 판 점수·최고 타일·종료 이유·개인 최고 갱신 여부·재도전 버튼을 표시합니다. 성공과 막힘은 별도 사실이며 같은 판에 모두 성립할 수 있습니다.
- 시작할 때의 최고점을 보관하여 이번 판 점수가 그 값을 엄격히 넘었는지 표시합니다. 동점은 “최고점과 동점”이며 갱신으로 표시하지 않습니다.

## 3. 흐름·입력 상태 [AC-F01~F06, AC-I01~I05]

| 상태/화면 | 허용 조작 | 차단/전이 |
|---|---|---|
| 홈 | 검색·장르·즐겨찾기·정렬·더보기·게임 선택 | 게임 방향 입력과 판 시작은 없습니다. 게임 선택으로 별도 페이지에 이동해 새 판을 시작합니다. |
| 플레이 | 보드 이동, Esc/일시정지, 재시작, 도움말, 정원, 음소거 | 게임 영역에 초점이 있고 문서가 보이며 입력 잠금이 없을 때만 이동합니다. |
| 이동 피드백 | 규칙은 이미 확정되어 있습니다. | 최대 120ms 입력 잠금, 방향 입력을 큐에 쌓지 않고 무시합니다. |
| 일시정지 | 수동 정지는 이어서하기, 보호 정지는 게임 재개, 재시작, 게임종료 | 보드·생성·타이머·지연 효과·효과음을 멈춥니다. 재개는 명시적으로 선택합니다. |
| 도움말/정원/재시작 확인 | 해당 창 조작, 닫기/취소 | 게임 입력을 차단하고 닫는 이벤트를 게임에 전달하지 않습니다. 이전이 플레이면 닫은 뒤 보드 포커스를 복구합니다. |
| 축하 | 계속하기 또는 결과 보기, 재시작 | 방향 입력을 차단합니다. 최초 성공 처리는 재개 시 반복하지 않습니다. |
| 결과 | 홈으로, 다시시작, 도움말, 기록/정원 | 방향 입력을 차단합니다. 재시작은 종료된 판이므로 추가 확인 없이 새 판을 시작합니다. |

- 게임 중 재시작은 “현재 판을 끝내고 새로 시작할까요? 최고기록과 해금은 유지됩니다.” 확인창을 엽니다. 취소는 기존 보드·점수·상태를 유지하고, 확인만 현재 판을 초기화합니다. 포기한 판은 막힘 종료 횟수에 넣지 않습니다.
- 탭 숨김(`visibilitychange`) 또는 창 포커스 이탈(`blur`)은 입력/스와이프/누른 키/지연 피드백을 초기화합니다. 이미 원자적으로 확정된 보드는 유지하고 자동 재개하지 않습니다. 다시 보일 때 명시적 재개를 요구합니다. 모달 중 이탈하면 모달을 유지하되 닫은 뒤에도 일시정지로 복귀합니다.
- 게임 페이지 새로고침은 새 판을 시작합니다. “진행 중인 판은 저장되지 않으며 기록과 정원은 유지됩니다”를 안내합니다. 페이지 진입 시 새 판 생성 외 자동 이동은 금지합니다.
- PC: 보드를 포커스 가능한 영역으로 만들고 방향키로 이동합니다. 처리하는 방향키만 기본 스크롤을 막습니다. 버튼·설정·외부 포커스에서는 게임 이동을 하지 않습니다. Esc는 게임 영역/게임 모달 맥락에서만 일시정지 또는 창 닫기로 처리하며, 재시작 확정을 대신하지 않습니다. 키 자동 반복은 무시하고 키를 놓은 뒤 다시 누르게 합니다.
- 모바일: 보드에서 시작한 단일 포인터 제스처만 받습니다. CSS px 기준 `max(|dx|,|dy|) >= 24`일 때 우세 축으로 1회 이동하고, 정확한 대각 동률은 무시합니다. 24px 미만 탭/흔들림·다중 터치·pointercancel은 무효입니다. 길게 누르기 자체는 반복 이동이 아닙니다. 보드 밖 스크롤은 정상이고 보드 안 스와이프만 스크롤과 충돌하지 않게 합니다.

## 4. 목표·기록·정원 [AC-P01~P04]

### 목표 안내

- 한 판 최고 타일에 따라 아직 도달하지 않은 첫 목표를 `128 → 256 → 512 → 1024 → 2048` 순서로 표시합니다. 예: 최고 타일 256이면 “다음 목표 512”입니다.
- 목표 배지는 도달/미도달을 숫자와 문양·텍스트로 구분합니다. 2048 이후에는 “2048 달성 · 계속 도전”으로 표시합니다. 목표는 확률/보드 크기를 바꾸지 않습니다.

### 기록 정의

| 항목 | 갱신 시점과 의미 |
|---|---|
| 현재점수/현재 판 최고 타일 | 새 판은 점수 0, 생성된 타일 기준 최고 타일로 시작합니다. |
| 최고점/역대 최고 타일 | 판 도중에도 새 기록이 생기면 즉시 갱신·저장합니다. 결과를 보지 않고 reload해도 기록이 사라지지 않습니다. |
| 시작한 판 수 | 명시적 시작/재시작/재도전 확정마다 1회 증가합니다. 준비·새로고침만으로 늘지 않습니다. |
| 막힘 종료 판 수 | 이동 불가가 처음 확정될 때 1회 증가합니다. 결과창 재개방으로 늘지 않습니다. |
| 2048 달성 판 수 | 한 판 최초 2048 달성 때 1회 증가합니다. 계속하기와 상위 타일은 중복 집계하지 않습니다. |
| 누적 유효 이동 수 | 실제 보드가 바뀐 방향 입력만 1회 증가합니다. |
| 누적 획득점수 | 각 이동에서 얻은 점수 증가량만 더합니다. 판 종료 시 현재점수를 다시 더하지 않습니다. |

### 정원 3종 — 제작 상세 결정

원안은 정원 수만 지정하였으므로 다음 명칭·문턱은 이번 제작 기준으로 구체화합니다. **기본 포함 총 3종**이며 별도 코스튬 3세트를 추가하지 않습니다.

| ID | 표시명/직접 제작 배경 | 해금 조건 |
|---|---|---|
| `seed` | 씨앗 뜰: 크림 바탕, 작은 새싹 | 기본 제공 |
| `grove` | 초록 숲: 잎과 낮은 관목 | 역대 최고 타일 256 이상 |
| `bloom` | 꽃 정원: 꽃과 가지 문양 | 역대 최고 타일 1024 이상 |

- 기록/정원 창은 세 카드의 미리보기·선택 표시·정확한 해금 조건·현재 역대 최고 타일을 보여줍니다. 잠긴 정원은 미리보기만 가능하고 적용 버튼은 비활성입니다.
- 해금은 즉시 저장하고 영구 유지합니다. 자동으로 선택을 바꾸지 않고 사용자가 선택/적용해야 합니다. 취소는 기존 테마를 유지합니다.
- 선택은 보드 주변 배경·타일 장식만 바꿉니다. 동일 입력과 난수에서 보드·점수·판정·성능은 같아야 합니다.
- 배경 성장/해금 피드백은 새 최고 타일이 생겼을 때만 짧게 표시합니다. 반복 점멸·상시 파티클·숫자 가림은 금지합니다.

## 5. 화면·접근성·피드백 [AC-V01~V04, AC-A01]

- 홈은 간결한 카드와 검색·장르·즐겨찾기·정렬 도구로 여러 게임을 탐색합니다. 별도 게임 페이지는 상단 제목/현재·최고점, 중심 4×4 보드, 다음 목표, 하단 일시정지·다시시작·게임종료를 배치합니다. 도움말·정원·음소거는 보조 도구로 유지하며 누적 기록은 보조 창에서 확인합니다.
- 차분한 크림 배경, 숲색 텍스트/주요 버튼, 낮은 채도의 흙색 보드입니다. 정원은 판 뒤나 옆에 두고 숫자와 조작을 방해하지 않습니다. 웹 기본 시스템 폰트를 사용하고 외부 폰트를 받지 않습니다.
- 모바일 320 CSS px부터 가로 넘침 없이 4열 정사각 보드를 유지합니다. 컨테이너의 사용 가능 폭에 맞춰 보드·간격·숫자를 함께 축소합니다. PC는 보드가 과도하게 늘어나지 않게 최대폭을 제한하고 정원/기록을 옆 또는 아래에 둡니다.
- 터치 버튼은 최소 44×44 CSS px, 안전 여백을 확보합니다. 낮은 화면에서는 페이지/모달 세로 스크롤을 허용하며 재개·재도전 버튼이 화면 밖에서 접근 불가능해지면 안 됩니다.
- 모든 타일은 실제 숫자 텍스트와 구분 문양을 함께 표시합니다. 테마/선택/잠금은 색만으로 전달하지 않습니다. 버튼은 키보드 Tab/Enter/Space로 접근 가능하고 포커스를 표시합니다. 모달은 포커스를 내부에 두고 닫으면 적절한 위치로 반환합니다.
- 합치기 피드백은 최대 120ms이며 감소된 모션 설정에서는 애니메이션을 제거/축소합니다. 축하·실패·저장 경고는 텍스트로도 표시합니다.
- 효과음은 합치기가 발생한 유효 이동마다 1회만 짧게 합성합니다. WebAudio를 사용자 시작/버튼 제스처 뒤에 활성화하고 실패하면 무음으로 계속합니다. 음소거 설정은 저장하며 초기값은 음소거입니다. 단순 이동/no-op/정지/숨김 탭에서는 소리 내지 않습니다.

## 6. 신규 자산과 권리 [AC-V04, AC-S03]

| 산출물 | 요구사항 |
|---|---|
| SVG 타일 11종 | `2,4,8,16,32,64,128,256,512,1024,2048` 각 1종입니다. 값마다 직접 만든 잎/씨앗 문양이며 숫자는 DOM 텍스트로도 표시합니다. |
| SVG 정원 3종 | `seed`, `grove`, `bloom` 각 1종입니다. 미리보기와 플레이 배경에서 같은 원본을 재사용할 수 있습니다. |
| SVG favicon 1종 | 잎과 격자 형태로 직접 제작합니다. |
| 합치기음 1종 | 외부 음원 파일 없이 WebAudio oscillator/envelope로 직접 합성합니다. |

- 전 자산은 이번 프로젝트에서 새로 제작합니다. 원안 참고 이미지를 다운로드·트레이싱·내장하지 않으며 원작 소스도 복사하지 않습니다.
- builder는 자산 목록에 파일 경로·직접 제작 여부·제작 방식·외부 저작물 미사용을 남겨야 합니다. SVG에는 스크립트·외부 참조·원격 폰트·추적 코드를 넣지 않습니다. 라이선스 양도 등 법적 약속은 이 설계서가 대신하지 않습니다.

## 7. 저장·오류·실행 [AC-D01~D05, AC-O01~O02, AC-S01~S03]

- 게임 전용 버전 키에 최고/누적 기록·해금·선택·음소거를 저장합니다. 판은 저장하지 않습니다. 필드/숫자 범위·버전·선택 소유권을 검증합니다.
- 읽을 수 없는 JSON·알 수 없는 버전·잘못된 구조는 기본 기록과 기본 정원으로 복구하고 1회 안내합니다. 이 경우 손상된 기록 보존까지 보장할 수는 없음을 알립니다. 유효한 숫자 기록은 유지할 수 있는데 테마 ID만 잘못된 경우 기본 테마로 복구합니다.
- 저장 권한/용량 문제는 예외를 잡고 메모리 플레이를 유지합니다. “이 환경에서는 기록이 저장되지 않습니다”를 표시하며 저장 성공으로 오인시키지 않습니다. 다른 웹앱 저장소를 지우지 않습니다.
- 빌드 후 로컬 Node 정적 서버와 브라우저만으로 플레이합니다. 로컬 서버를 켠 상태에서 외부 인터넷을 끊어도 시작·플레이·정원·음소거·저장이 동작해야 합니다. 첫 접속 이전 서버 종료 상태나 임의 `file://` 직접 실행은 보장하지 않습니다.
- 실행·빌드 명령은 PM/builder가 실제 실행 후 인수인계에 기록합니다. 본 문서에는 실행하지 않은 명령을 검증 완료로 기록하지 않습니다.
