## 구현

2×2 숫자/문양/이름 패드, 밤하늘·새벽 테마, 기본 무음 WebAudio 합성음, 명시적 시작, 순서 시범과 따라 하기, 입력마다 5초, 결과/재도전/홈을 구현했습니다. 순서는 최초 1개이며 완주한 기존 prefix 뒤에 RNG 1회로 한 개만 추가합니다. 같은 패드 연속 입력에는 논리 잠금을 두지 않습니다.

최초 400ms 준비, 500/450/400ms 점등, 중간 250ms 간격, 마지막 소등 400ms, 성공 700ms를 순수 delta 엔진에서 처리합니다. 모든 하위 상태와 피드백의 남은 시간을 정지/모달에서 보존하고 명시적으로 재개합니다. 각 입력 이벤트에서 `performance.now()`로 실제 시간을 먼저 정산하고 RAF에서도 콜백 도착 시각을 사용합니다. 250ms 초과 공백은 시간 진행 없이 보호 정지합니다. 예약된 게임 타이머는 없으며 엔진 advance token과 오디오 generation이 이전 판/취소 콜백을 방어합니다.

포인터는 문서 전체의 접촉 수, 동일 패드 down/up, 이동 8px 이하, 취소/lost capture/다중 포인터를 확인합니다. 실제 pointerup에서 한 번 처리하고 후속 pointer click은 무시합니다. 키보드는 놓은 키당 한 번만 버튼을 활성화하며 숫자 1~4는 패드 초점에서만 처리합니다. 모달 Tab 순환, Esc 취소, 실제 trigger 복귀, 모달 중 보호 사유 우선이 있습니다.
