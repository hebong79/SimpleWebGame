# G018-06 · 풍선 참새 — 제작 설계 v1.0

PM·설계·디자인: 대현자. 구현: **native cody-02**. 원안06_flappy.md/공통사양읽기전용, 공통 G018_COMMON_CONTRACT.md와함께적용. 원작브랜드/픽셀새/배관그래픽을복제하지않습니다. 풍선은작은장식이며게임판정은참새본체원형만사용합니다.

## 1. 제품·시각 방향
2D한버튼비행, PC Space/클릭·모바일탭. 목표10초~2분은체험목표이며사람시험전달성주장금지. 무한기록형으로성공/완료미션을새로만들지않습니다. 원안의'성공·실패결과'공통항목은이게임에서는통과득점피드백과비행종료결과로적용합니다. 경로 /games/06-flappy/index.html, ID balloon-sparrow.

주표면 **Operate**, 보조옷장 **Configure**. 낮은채도의하늘#e8f3eb,크림#f6f3e9,잉크#284d3b,정원아치#55775c,참새갈색#8a563b,포인트해바라기#e7b451. 시스템폰트,점수tabular-nums,넉넉한빈틈/한개의주행동. PC는세로경기장왼쪽·기록/옷장오른쪽,모바일은점수위·경기장·큰'날갯짓'버튼·접히는옷장/기록아래. 메뉴/옷장이터치영역과겹치지않습니다. 패배피드백은흔들림대신작은정지+텍스트,감소된모션시날갯짓/배경움직임도최소화합니다.

## 2. 물리·생성 확정
- 논리화면360×640. 원형캐릭터중심x=96,초기y=320,반지름12; 장식/부리/풍선/날개는충돌크기에추가하지않습니다. vy초기0, 중력900px/s²,각유효탭은vy=-280px/s로재설정(가산아님). 시작동작은한번의초기flap도포함합니다.
- 고정시뮬레이션1/120초+RAF누산기. 각tick에서 y += vy*dt + 0.5*900*dt², vy +=900*dt, 아치x -=110*dt. 입력은각다음tick직전에한번확정하며동일타임스탬프이벤트순서를보존합니다. 프레임분할30/60/120FPS에서같은시각입력의물리/점수/결과가같아야합니다. 순수advance의시간나머지는누산기에유지합니다.
- 아치폭52, 인덱스n=1부터, 첫아치앞면x=420,이후앞면간격220. 멀리있는모든아치를미리만들지않고필요한수만유지하되인덱스/RNG순서를보존합니다. 속도110항상고정. 앞/뒤판정은아치좌우면x와x+52입니다.
- 첫5개틈중심320·높이180. n≥6이면 h=max(160,180-5*(n-5)):6=175,7=170,8=165,9부터160. 각 틈의 상단≥100, 하단≤540(화면천장/바닥에서100여백). 중심c∈[100+h/2,540-h/2]이고 직전중심과차이≤80. 주입RNG를구간[max(100+h/2,prev-80),min(540-h/2,prev+80)]에균등매핑합니다. 첫5개는랜덤소비0이며새아치마다한번만소비합니다. 초기미리보기·메뉴재렌더는소비하지않습니다.
- 원과상단/하단아치직사각형의최근접점거리²≤12²이면충돌, y-12≤0 또는 y+12≥640이면천장/바닥충돌입니다. 경계접촉포함. 고정tick안에서빠른이동으로접촉을건너뛰지않도록원-확장직사각형sweep/동등연속검사를포함합니다. 충돌의정확한지점/시각을이벤트에남깁니다.
- 중심x=96이아치뒤면(x+52)을엄격히넘었고alive인경우해당n에서1점. 동tick에충돌과통과가함께관측되면충돌을우선하여해당tick새점수를주지않습니다. 고유n의passed플래그로중복0. 화면밖아치는득점여부유지후정리합니다.

## 3. 상태·입력·재도전
준비에서시작버튼/경기장primary탭/초점Space는새판생성+최초flap1회. 플레이중Space/경기장탭/큰날갯짓버튼은flap1회,키repeat·중복pointer/click합성·다중접촉은제외. 경기장탭은primary pointerdown으로명확한탭의도만처리하되30px이상drag/secondtouch가확인되면추가입력/유지반복을취소합니다. 이미확정한첫flap을소급취소하지않고다중접촉동안후속flap0을보장합니다. 페이지바깥scroll/모달클릭은게임입력아님. P/Esc/정지버튼과blur숨김보호정지를지원합니다.

충돌시lost를동기확정하고화면·저장·음향도한번. 애니메이션대기중추가득점/추가결과불가. 결과확정후500ms동안재도전입력잠금, 그뒤에발생한새로운눌림만새판시작+flap1회로처리합니다. 충돌직전부터유지중인Space/포인터·0.5초전에눌렀다늦게놓은입력은새판을열지않습니다. 버튼의disabled와남은잠금안내를표시합니다. 홈/도움말은즉시접근가능합니다. 결과문구는통과수·종료이유(arch/ceiling/ground/quit)·개인최고비교·옷해금과재도전입니다. '승리'로표시하지않습니다.

## 4. 옷장·레이어
본체날갯짓3프레임fly0/fly1/fly2,충돌hit1개. 로컬SVG원본에서96×96viewBox,본체중심(48,48),판정radius12논리단위와혼동하지않게렌더scale를명시합니다. 레이어:뒤풍선장식→몸→몸옷→머리→발목→눈/표정. 모든의상은같은프레임·기준점. 누락프레임은해당부위를기본외형으로복구합니다. 과한돌출은아치경계를가리지않습니다.

| 세트ID/명칭 | 3부위 아이템ID(머리/몸/발목) | 영구해금 |
|---|---|---|
| basic/기본참새 | none/none/none | 항상 |
| pilot/파일럿 모자 | pilot-head/pilot-body/pilot-ankle | 완료한판최고≥1 |
| rain/비옷 | rain-head/rain-body/rain-ankle | 완료한한판최고≥10 |
| bee/꿀벌 옷 | bee-head/bee-body/bee-ankle | 완료한판누적통과≥100 |

정확한문턱·현재진행·잠금사유를각세트에표시합니다. 1개세트해금시3부위동시소유,중복지급없음. 부위자유조합·전체세트장착·none가능·3프레임동작미리보기. locked는preview만, 적용불가. 옷장draft와현재equipped를분리하고'장착하기'만영구반영,취소시원상태·닫기이벤트차단. 플레이중열면보호정지와동일하게명시재개필요. 결과전현재판업적은예정해금으로안내하고영구소유로우회하지않습니다. 코스튬별동일입력/seed를재생해충돌·점수·위치/속도 일치를검증합니다.

## 5. 저장과 음향
키 simplegames.flappy.v1, 스키마version1: bestScore,totalPassed,plays,collisions,quits,unlockedSets,equipped{head,body,ankle},muted. 기본0/0/0/0/0/[basic]/{none,none,none}/true. plays=collisions+quits, bestScore≤totalPassed; unlockedSets는기록으로재계산한소유와일치시켜유효하지않은해금/장착은기본으로복구합니다. 자연충돌은collision횟수,사용자중도종료는quit. 결과시에각통계+해금원자커밋1회. 0점종료도plays1. 새로고침미완주기록은버리고기존완료기록/옷은보존한다고안내합니다. 음소거·옷장설정저장은미완료판통계를포함하지않습니다.

합성통과/충돌효과음,기본무음. 신기록·통과·해금은무음에서도텍스트/작은시각표시로알립니다. 상시입력딜레이/진동권한/강제음악·외부음원없음. 원안참고이미지를다운로드·트레이싱하지않습니다. PM키트도자체작성입니다.

## 6. 설계 경계 사례
1. 같은아치뒤면을여러tick지나도+1한번,동tick충돌이면+0/lost1회.
2. 반지름접촉(tangent)·천장/바닥정확경계는충돌. 의상끝접촉만으로는충돌없음.
3. 첫5개고정높이/6~9틈175/170/165/160,모든중심은여백100와인접차80제약유지.
4. 같은입력타이밍·seed를30/60/120FPS분할재생해좌표·점수·결과동일. 정지10초는물리/생성/난수소비0.
5. 499ms재도전거부,500ms후새눌림은허용,미리누른키유지는거부.
6. 한판10점결과는pilot/rain을한번해금. 기존totalPassed99에서+1결과는bee해금,옷장재개방누적+0.
7. 잠긴아이템/다른부위ID/손상값은기본복구하고draft취소는영구저장0.
8. quit확정은현재 통과를한번정산,확인취소/홈결과재개방은추가0.
