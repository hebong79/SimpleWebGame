# 대현자 G-016 v1.1 보완 인수

## 5.1 v1.1 확정 보완 — 누적 기록·중도 종료 (G016-DQ-01)

- `plays`는 **결과가 확정된 판 수**입니다. 단순 ready 표시/임무 시작만으로 늘리지 않습니다. 시작한 판의 승리·목숨 소진·확인한 중도 종료(새 임무/홈)는 각1회 집계합니다. ready에서 시작하지 않고 새판/홈, 확인창 취소, pause/blur, 이미 저장한 결과 재표시/reload는 증가시키지 않습니다.
- `wins`는 3스테이지를 모두 완료한 결과에서만1 증가합니다. 자발 종료는 승리/목숨소진 패배로 오인하지 않습니다. 화면의 '임무 완료'는 wins를 표시합니다.
- `bestStage`는 **결과가 확정된 판에서 진입했던 최고 스테이지(도달 단계)**입니다. 기본0, 시작한 판을 stage1에서 중단하면1, stage2 진입 직후 중단하면2입니다. 통과 횟수가 아닙니다.
- `totalBricks`는 **해당 판에서 실제 제거한 모든 벽돌의 수**를 결과 시 한 번만 누적합니다. stage별32개이므로 stage2 진입 즉시 종료는32개, stage3 진입 즉시 종료는64개, 승리는96개입니다. score에서 보너스를 제거하지 않은 채 벽돌 수를 역산하지 않습니다. 전체 판 누적값은 유한 안전정수로 안전하게 제한합니다.
- `bestScore`는 모든 확정 결과의 점수 최댓값입니다. 개인 최고 갱신은 새 점수가 기존 점수보다 **엄격히 클 때**만 표시하며0점/동점은 '새 기록'이 아닙니다.
- 진행/정지 중 새 임무·홈을 **확인**하면 기존 판을 `endReason:'quit'`으로 확정 → stats를1회 반영/저장 시도 → 새판 ready 생성 또는 홈 이동 순서입니다. 재시작/홈은 통과 보너스를 추가하지 않습니다. 확인 취소는 기존판을 paused로 보존하고 stats는 그대로입니다. 이미 finished이면 기존 결과를 다시 집계하지 않습니다.
- 시작하지 않은 ready에서는 `finishGame`을 통해 임의의 plays를 만들지 않습니다. 확인한 중도 종료는 실제로 시작한 playing/paused 판만 대상으로 합니다. 창/탭을 닫기 전 진행 중 판을 복원하는 기능은 첫 범위에 없고, blur/숨김은 결과가 아닙니다.
- 정상 첫 방문의 `getItem(...)===null`은 **저장값 부재**로 정상 기본값을 사용하며 저장 불가 경고를 내지 않습니다. JSON 문자열 `'null'`, 손상 JSON, 구버전은 유효하지 않은 저장 내용으로 복구 안내를 할 수 있습니다. 실제 getter/getItem/setItem 예외·저장 실패는 지속 경고와 메모리 기록을 유지합니다.
- B11의 입력 무효는 시간/이동/발사 등 경기 진행을 뜻합니다. 임무 시작/계속하기/재도전 같은 명시적 상태 전이 버튼 자체를 금지하는 뜻이 아닙니다.
- 모바일 safe-area-inset과 320px/가로667×375에서 결과·확인창 조작에 스크롤로 접근 가능해야 합니다. 모든 실제 터치 버튼은 너비와 높이 모두44CSSpx 이상입니다. 원본 벡터 키트의 배치와 달리 실제 물리 y884는 본문 고정값을 따릅니다.
