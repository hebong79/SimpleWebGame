## 수정 내용

### 옷장 native select 제거

- `index.html:14`: 머리/몸/발목의 native select를 접근성 이름을 가진 `role="group"` 컨테이너로 교체했습니다. ID `part-head`/`part-body`/`part-ankle`는 유지했습니다.
- `main.mjs:56`: 각 부위에 기본/파일럿/비옷/꿀벌 버튼을 생성합니다. 각 버튼은 `type="button"`, `data-part`, `data-item`(`none`, `pilot-head` 등), 접근성 이름 및 `aria-pressed`를 갖습니다. 버튼의 기본 키보드 Enter/Space 활성화와 Tab 접근을 사용하며 라디오 역할을 가장하지 않습니다.
- `main.mjs:49`: 실제 draft로 부위별 선택 상태, 보유/잠김 표시와 접근성 이름을 갱신합니다. 잠긴 버튼도 클릭·키보드로 미리보기할 수 있고 기존 `wardrobe.canApply()`/`apply()`가 적용을 막습니다.
- 기존 세트 버튼, 장착/취소 리스너, draft/소유권/저장 함수는 그대로 사용합니다. 취소/미리보기는 저장하지 않습니다.
- CSS: `minmax(0,1fr)`/`min-width:0`와 줄바꿈을 적용하고 버튼 높이는 최소 44px입니다. 좁은 화면에서는 부위가 단일열, 각 부위의 버튼은 두 열입니다. 기존 모달 `max-height`와 `overflow:auto`를 보존했습니다. 실제 320px 터치 크기/레이아웃 측정은 PM 브라우저 검증 대상입니다.

### Enter/Space 키 반복 차단

- `main.mjs:75`: 버튼 대상 Enter/Space `keydown`에서 `repeat=true`이면 즉시 `preventDefault()` 후 반환하여 UA 기본 합성 click 발생을 막습니다. 반복 키는 재도전 토큰도 갱신하지 않습니다.
- 최초 `keydown`은 기본 활성화를 취소하지 않고 기존 DOWN 토큰을 생성합니다. 새 DOWN, 정상 pointer 경로, 기존 500ms 재도전 gate, 경기장 키 처리와 `#flap` click 리스너는 변경하지 않았습니다.
- 원본 독립 재현은 정지된 가상시계에서 Enter DOWN → 100ms → repeat DOWN → 25ms 후 대조군과 위치를 비교했습니다. 여기서는 지시대로 그 브라우저 재현을 실행하지 않았습니다. fresh reviewer가 새 코드에서 trusted 입력으로 재검증해야 합니다.
