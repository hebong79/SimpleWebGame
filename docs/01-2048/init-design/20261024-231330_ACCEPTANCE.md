### 보드 fixture

- **B-01 막힘:** `[[2,4,2,4],[4,2,4,2],[2,4,2,4],[4,2,4,2]]`입니다.
- **B-02 성공과 막힘 동시:** `[[1024,1024,4,8],[2,8,16,32],[4,16,32,64],[8,32,64,128]]`를 왼쪽으로 이동한 뒤 유일한 빈칸 `(행0,열3)`에 2를 생성합니다. 최종 `[[2048,4,8,2],[2,8,16,32],[4,16,32,64],[8,32,64,128]]`는 빈칸/동일 인접 쌍이 없습니다. 시작 조건은 이번 판 성공 미처리입니다.
- 최초 승리 검증 fixture는 정상 시작 절차를 대신하는 테스트 어댑터 데이터입니다. 이를 일반 사용자가 처음부터 해당 판으로 시작하는 기능으로 구현하지 않습니다.

## 6. 장애 저장·복구 테스트

실제 브라우저 저장과 별개로 자동 테스트는 가짜 Storage 어댑터를 사용할 수 있습니다. 손상 데이터 테스트 전 해당 게임 키만 백업하고, 다른 앱/게임의 저장소를 지우지 않습니다.

| ID | 종류 | 절차/입력 | 기대 결과 |
|---|---|---|---|

## 8. 환경·증거·완료 게이트

### 후속 검증 환경 최소 기록

| 구분 | 기록해야 할 내용 | 현재 상태 |
|---|---|---|
| 엔진/상태/저장 자동 | 실제 명령, Node/TS 버전, 종료 코드, 케이스별 결과, 로그 | 미실행 |
| 빌드/HTTP 자동 | 빌드/서버 명령, 포트, 응답/헤더·탈출 요청 결과 | 미실행 |
| PC 브라우저 | 브라우저/버전, OS, viewport, 키보드·포커스·모달 확인 | 미실행 |
| 모바일 에뮬레이션 | 브라우저/버전, CSS viewport, 포인터 이벤트/스크린샷 | 미실행 |
| 실제 모바일 | 기기·OS·브라우저, 실제 터치·회전·안전 여백·소리 | 미실행; 에뮬레이션으로 대체했다고 숨기지 않습니다. |
| 외부망 차단 | localhost 유지 방식, 외부 요청 목록, 캐시 영향 여부 | 미실행 |

- PC의 Chromium 계열과 가능한 Firefox 계열에서 핵심 흐름을 확인하고, 모바일은 Android Chrome/iOS Safari를 가능한 환경에서 확인합니다. 미보유 기기·실기기 LAN 승인 대기는 명시적 잔여 위험으로 남겨 PM이 판단합니다. 브라우저 지원을 확인 없이 보장하지 않습니다.
- 모든 필수 ID가 실제 통과하고, 빌드·서버·PC·터치·저장·오프라인·보안 증거를 PM이 읽은 뒤에만 제작 수용을 결정합니다. 수행 불가 항목은 PM의 명시적 보류/위험 수용 없이 통과로 바꿀 수 없습니다.
- G-001 완료 게이트는 **세 설계 문서의 생성 및 실제 재열람·요구사항 추적 확인**입니다. 게임 구현/테스트 통과 게이트와 분리합니다.
- 본 worker는 허용된 세 문서만 수정하며 BACKLOG/DECISIONS/HANDOFF·코드·자산·보드 게시 상태는 변경하지 않습니다. PM에게 실제 산출물 경로와 문서 검증 결과를 인계합니다.
