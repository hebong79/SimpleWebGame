# G029 18 · 젤리 한입 설계와 수용 기준

공통 계약 `../20261101-224000_G029_PM_CONTRACT.md` 적용. 1인 점수퍼즐, 목표1~2분, 제한시간 없음.

## 규칙·콘텐츠

- mode easy=8행8열3색, normal=10행10열3색(기본), extra=10행10열4색. 준비의 명시적 버튼으로 선택, 진행중 변경은 새판 확인. 모드별 기록 분리.
- 각 칸색을 균등 난수로 생성, 정리 가능 보장 없음을 명시. 시작부터 legal group가 없으면 원안의 무작위 성질을 유지하고 즉시 종료·정산해도 되나 준비 화면에서 무단 판 생성·저장 금지.
- 상하좌우 같은 색 flood fill(대각선 제외). 2개 미만은 선택/제거되지 않고 명확한 안내만 표시.2개이상 첫 클릭은 묶음 미리보기, 같은 연결성분 재클릭으로 제거. 다른 유효묶음 클릭은 선택 교체, 선택 취소는 보드·점수불변. 선택 셀 자체가 아니라 같은 성분 어느 칸 재클릭도 확정.
- n개 제거 점수(n-2)^2.2개=0,3개=1. 선택 예상점수는 제거점수만(전부비움 보너스는 별도 안내). 보드 전부 비우면500점 정확히1회. 제거 후 열별 아래로 안정 압축, 완전히 빈 열 제거·오른쪽 열 왼쪽 안정 압축. 잔여 크기 좌표와 빈칸을 일관되게 유지.
- 제거는 원자적으로 점수·남은 블록·보드확정,200ms 논리 collapse lock. 정지/모달은 남은 lock 동결, lock 완료 후 더 이상2개묶음 없으면 결과. bonus/기록은 엔진 완료처리1회. 애니메이션 callback에서 규칙 처리 금지.
- 종료사유 all-clear 또는 no-moves, 결과 점수·제거횟수·남은 수·완전정리보너스·개인최고/동점 표시. 포기/새판/홈은 미완료판 정산 안 함. undo는 원안에 없으므로 없음(취소는 선택 취소).
- 방향키 셀탐색·Enter/Space 선택/확정. 사라진 좌표는 유효칸으로 clamp, 빈판은 보드초점 안전. 크기가 바뀌어도 다음 입력이 엉뚱한 그룹으로 전달되지 않음. 선택중 스타일/preview 이외 보드는 변하지 않는다.
- mode별 bestScore/max, bestRemaining/min 및 finished/allClears/totalScore. 유효한 0점 완료도 기록, bestRemaining 초기는 null 허용. theme sugar|night, muted boolean, lastMode. 결과1회/명시설정변경만 저장.
