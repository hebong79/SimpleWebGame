## 6. 미검증 / 제한
- 실제 blur/hidden 전환: headless에서 `bringToFront`로는 `visibilityState`가 visible로 유지됩니다. 그래서 보호정지는 `blur`/`visibilitychange`/`pagehide` 합성 이벤트로만 확인했습니다(자동 검증, 실제 OS 포커스·탭 숨김 아님).
- WebKit은 터치 CDP가 없어 마우스(hasTouch 컨텍스트)로 대체했습니다. `touchscreen.tap` 즉시 탭은 선택을 시도한 기록만 있습니다. 모바일 멀티포인터는 Chromium CDP만 검증했습니다.
- 물리 기기·실제 Safari·실제 손가락, 스피커 청취(WebAudio 합성음은 켜고 끈 흐름만 확인), 스크린리더, 사람의 1~2분 체감, 공통 후보 빌드, 홈 통합, 3116/LAN 실제 실행은 이번 범위 밖이라 미검증입니다. 자동 검증과 시각 확인만 수행했고 실물 수동 플레이는 하지 않았습니다.
- 초기에 하네스 오류(PC 비터치에서 `touchscreen`, 기대 round 값, JSON 키 순서, retry 포커스에서의 Enter)로 4건이 실패했습니다. 제품 결함이 아니고 스크립트 수정 후 재실행했으며 원 로그는 `RUN/pc-run1-harness-issues.log`에 보존했습니다.
