## 6. 미검증 / 제한
- 실제 Safari/iPhone, 실물 기기, 실제 손가락, 스피커 청취, 스크린리더(VoiceOver/TalkBack)는 미검증입니다. 합성 click 복구는 `element.click()`로만 확인했고 실제 보조기술의 클릭 경로는 모릅니다.

- 실제 blur/hidden 전환은 headless에서 `visibilityState`가 visible로 유지되어 합성 이벤트로만 확인했습니다. PC에서 scroll 취소는 보드가 스크롤되지 않는 환경이라 합성 scroll 이벤트로 확인했고, 모바일에서는 실제 scrollLeft/scrollTop 변경으로 확인했습니다.
- WebKit 스크린샷 도구가 CSP 소음을 만들기 때문에 WebKit 기능 검사는 스크린샷 없이 실행했고 시각 검토는 Chromium만 했습니다.
