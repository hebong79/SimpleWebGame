## 기존 회귀의 의미 변경

- `/`는 홈이므로 게임 회귀 진입을 `/game.html`로 바꿨습니다. 게임 페이지는 자동 새 판을 시작하므로 숨겨진 시작 버튼 클릭을 제거했습니다.
- 기존 01의 준비 화면 무입력 구간은 홈에서 게임 기록이 생성되지 않음 → 명시적 게임 선택 → 새 페이지에서 2타일 생성으로 바꿨습니다. 새로고침은 새 판이므로 시작한 판 수가 증가합니다.
- Esc·자동 이탈 정지는 `게임 재개`, 일시정지 버튼을 직접 누른 정지는 `이어서하기`로 구분합니다.
- 결과 모달의 기존 기록·정원 진입 버튼은 새 홈/재시작 흐름에 따라 제거되었습니다. 05에서는 결과 Escape 차단과 집계 중복 방지를 확인하고, 재시작 뒤 보조 기록 창을 열어 기록 보존을 확인합니다.
- 결과의 재도전 버튼 이름은 `다시시작`으로 변경했습니다. 승리의 `계속 도전하기`는 유지합니다.
- 테스트 수를 줄이거나 실패를 건너뛰지 않습니다.

## 실행 방법

기본 Playwright 서버는 `dist`를 사용합니다. 이번 작업은 PM이 작성한 격리 빌드를 다음과 같이 선택합니다.

```powershell
$env:GAME_TEST_BUILD_DIR = 'artifacts/g013-build'
node node_modules/@playwright/test/cli.js test
```

테스트 서버는 loopback 3103이며 `reuseExistingServer: false`로 기존 서버를 재사용하지 않습니다. `npm run build`, `npm test`, 기존 PM2 변경은 QA에서 실행하지 않습니다.

## G013-QA001 — WebKit 홈 CSP 오류

- 최초 WebKit 01에서 console 오류 2건을 발견했습니다. 별도 WebKit 페이지에서 홈 `goto` 후 200ms 대기만 해도 재현되며 스크린샷을 전혀 호출하지 않았습니다. 오류는 `Refused to apply a stylesheet ... style-src directive`이며 위치는 홈 HTML 27/30 인접입니다. 따라서 기존 WebKit 스크린샷 도구 오류와 구분했습니다.
- 홈 담당 worker 원인 분리: JS 전체 빈 모듈, 외부 CSS 제거, `art.style.setProperty` 제거에서도 동일 2건이 남았고 HTML native select 두 개 제거 시에만 0건이었습니다. 상세 브라우저 내부 원인은 추정이며 native select 존재와 발생의 연관을 확인했습니다.
- PM 결정: CSP를 완화하지 않고 장르를 기존 버튼으로 PC·모바일 통일하고 정렬을 `details/summary`와 3개 버튼으로 대체합니다. QA는 `selectOption`을 동일 정렬 값 버튼 선택으로 변경하고 정렬 후 메뉴 닫힘·포커스 복귀도 검사합니다.
- 신규 홈 통합 시나리오에도 console/page 오류·외부 요청 증거와 0건 단언을 추가했습니다.
- 수정 후 별도 무캡처 WebKit 홈 확인도 오류 0건, select 0개, 초기 카드 12개로 통과했습니다. `artifacts/g013-qa/csp-final.json`을 참조하세요. 최종 전체 75개 회귀에서도 같은 문제는 재현되지 않았습니다.

## 확인한 실제 동작과 한계

- 홈에서 실제 URL로 게임에 들어가고, 난수만 고정한 브라우저 방향키 입력으로 2+2 합치기 및 4점을 만든 뒤 종료했습니다. 결과의 실제 4점 전달, 종료창에서 이어서하기 부재, 자발 종료의 막힘 종료 횟수 0 유지, 홈 복귀 후 최고 4점 보존과 새 판 시작을 3프로젝트에서 확인했습니다.
- 승리·동시 막힘·4096은 기존 QA 네트워크 fixture 방식으로 첫 시작 보드를 주입하되 이후에는 실제 규칙과 입력을 실행했습니다. fixture와 실제 초기 판 검증을 구분합니다.
- 직접 일시정지와 자동 blur/Esc 정지의 재개 문구, 정지 중 재시작 취소 복귀와 보드 보존, 정지 중 종료, 종료 결과 Escape 차단을 확인했습니다.
- 홈 30개 전체, 12/24/30개 표시, 태그/이름/장르/상태/즐겨찾기 복합 필터, 정렬 3종, 저장 차단, 키보드 포커스, 0결과 초기화, 320/390/768/1440px 가로 넘침과 44px 조작, 마지막 카드·맨 위로 이동을 확인했습니다.
- 보안 증거의 실제 console/page 오류와 외부 요청은 0건입니다. Playwright WebKit 스크린샷 도구의 기존 CSP 메시지는 `screenshotToolErrors`로 별도 보존하며 앱 오류와 합산하지 않습니다. 홈 native select 문제는 무캡처 재현 및 제거 후 재검증하여 그 도구 메시지와 구분했습니다.
- 알려진 차단 사항은 없습니다. 사용자의 실제 물리 모바일·음향 청취·수동 플레이 수용은 미검증이며 PM 최종 통합·재실행 및 운영 전환은 QA 완료와 별개입니다.
