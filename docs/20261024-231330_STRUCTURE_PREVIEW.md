# 홈과 게임 화면 구조 시안 — G-010

2026-10-23 사용자 요청에 따른 검토용 시안입니다. 기존 게임에 구조 변경을 적용하는 작업은 다음 단계입니다.

## 화면과 흐름

- `prototype/index.html`: 여러 게임을 고르는 홈입니다. 숫자 정원 2048만 선택할 수 있고, 추가 게임은 준비 중으로 표시합니다.
- `prototype/game.html`: 별도 주소의 게임 화면입니다. 시안의 점수와 보드는 예시이며 실제 2048 규칙을 실행하지 않습니다.
- 플레이 화면에는 일시정지, 다시시작, 게임종료를 배치합니다.
- 일시정지를 누르면 정지 팝업에 이어서하기, 다시시작, 게임종료를 표시합니다. 이어서하기는 정지 팝업에서만 표시합니다.
- 게임종료를 누르면 결과 팝업에서 점수와 최고 타일, 종료 사유를 보여줍니다. 홈으로를 누르면 게임 목록으로 이동합니다.
- 진행 중 다시시작은 확인을 거치며, 결과에서 다시시작하면 새 판 화면으로 이동합니다.
- 시안 외부의 결과 화면 보기 버튼으로 자연 종료 결과도 확인합니다.

## 시각 방향과 자산

기존 숫자 정원의 크림색 배경과 숲색 강조를 공통 홈으로 확장합니다. PC는 게임 보드와 정원 안내를 나란히, 모바일은 위아래로 배치합니다. 새 게임 카드를 추가할 수 있는 목록 구조를 사용합니다.

향후 게임명과 분류, 점수와 보드는 시안을 위한 예시입니다. 실제 출시·추가 게임 제작을 의미하지 않습니다. 기존 프로젝트의 직접 제작 SVG만 재사용하며 외부 이미지·폰트·라이브러리를 추가하지 않습니다. 자산 출처와 권리 기록은 `01-2048/init-design/20261024-231330_ASSETS.md`를 따릅니다.

## 실제 구현 시 후속 설계

이번 시안은 기존 단일 게임 범위를 홈 구조로 확장하자는 제안입니다. 검토 후 `01-2048/init-design/20261024-231330_GAME_DESIGN.md`의 통합 런처 제외 항목과 `01-2048/init-design/20261024-231330_TECHNICAL_DESIGN.md`의 화면·상태 정의를 갱신합니다. 게임 목록 등록 구조, 실제 URL 라우팅, 기존 게임 입력 잠금과 정지·종료·기록 처리, 2048 달성 후 계속 도전 흐름은 실제 구현 단계에서 통합합니다.

진행 중인 판의 새로고침 후 복원은 이번 요청 범위에 추가하지 않습니다. 이어서하기는 현재 페이지에서 일시정지한 판에만 적용합니다.
