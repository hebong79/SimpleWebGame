# G-011 · 30개 이상 게임을 위한 홈 탐색 시안

2026-10-23 사용자 요청. 기존 화면의 크림색·숲색과 게임 페이지 흐름을 유지하면서 홈을 개편합니다. 실제 게임 구현이나 운영 서버 변경은 이번 범위에 포함하지 않습니다.

## 기존 홈의 수용 범위

기존 CSS 격자는 카드를 추가하면 행을 늘리고 문서가 자연스럽게 세로 스크롤되는 구조입니다. 따라서 개수 자체에 3개 제한은 없습니다. 다만 큰 도입부와 큰 카드, 탐색 도구가 없는 상태에서는 20~30개의 게임을 비교하거나 다시 찾기 어렵습니다. 스크롤과 함께 검색·분류 기능이 필요합니다.

## 시안 기준

- 예시 카탈로그 30개: 숫자 정원 2048 화면 시안 1개, 준비 중인 가상 게임 29개. 구현 완료 게임 수로 표현하지 않습니다.
- 도입부를 줄이고 카드의 그림·설명을 간결하게 만들어 PC에서 최대 4열로 봅니다. 모바일 최소 320px부터 읽기 쉬운 열 수로 전환합니다.
- 검색과 장르·즐겨찾기·상태 조건을 함께 적용하고, 기본순·이름순 등의 정렬을 제공합니다. 검색 결과와 현재 표시 개수를 정확히 안내합니다.
- 최초 12개, 더보기로 24개·30개까지 표시합니다. 조건을 변경하면 다시 처음 12개부터 표시합니다. 모든 결과가 표시되면 더보기 버튼을 제거합니다.
- 30개는 예시 데이터 수입니다. 전체 개수와 더보기의 마지막 위치는 카탈로그 길이에서 계산하여 이후 30개를 넘어도 같은 구조로 추가할 수 있게 합니다.
- 문서 전체를 세로 스크롤합니다. 목록에 별도의 좁은 스크롤 영역을 만들지 않습니다. 탐색 도구를 간결하게 고정하고 맨 위로 돌아가는 동작을 제공합니다.
- 결과가 없으면 조건을 초기화할 수 있습니다. 즐겨찾기 저장에 실패해도 현재 화면 조작은 유지합니다.
- 게임 카드의 즐겨찾기와 실행은 독립적인 조작입니다. 준비 중 게임은 실행하지 않습니다.
- 기존 숫자 정원 게임 페이지와 정지·재개·재시작·종료 결과·홈 복귀 흐름을 유지합니다.

## 파일과 검증 경계

시작 화면은 계속 `prototype/index.html`입니다. 홈 전용 `home.css`와 `home.js`를 사용하고 기존 게임 페이지의 스타일과 스크립트는 유지합니다. 추가 자산은 기존 직접 제작 SVG와 새 CSS 도형만 사용하며 외부 자산·폰트·런타임 의존성을 추가하지 않습니다.

브라우저 자동 검증은 30개 전체 접근, 복합 검색·필터·정렬·즐겨찾기, 스크롤 및 320/390/768/1440px 화면을 다룹니다. 실제 게임 플레이나 모바일 실기기 검증과는 구분합니다. 결과와 실행 명령은 완료 후 HANDOFF에 기록합니다.
