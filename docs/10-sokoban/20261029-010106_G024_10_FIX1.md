## 수정 범위와 자체 리뷰

`public/games/10-sokoban/engine.mjs`의 `move()` 시작에 아래 한 줄만 추가했습니다.

```js
if (typeof direction !== 'string' || !Object.hasOwn(DIRECTIONS, direction)) return state;
```

문자열 여부를 먼저 확인하므로 객체·함수·프록시의 property-key 강제 변환을 실행하지 않습니다. 이어서 동결된 `DIRECTIONS`의 own key인 리터럴 `U/R/D/L`만 허용합니다. 상속 속성명, 일반 잘못된 문자열, 비문자열은 동일한 상태 객체를 반환합니다. 기존 이동/밀기/승리/undo 코드, 방향 정의, 공개 API는 그대로입니다.

`tests/games/10-sokoban.test.mjs`에는 좁은 방향 입력 회귀 42개만 추가했습니다. Object.prototype의 12개 own 이름, 잘못된 문자열 7개, null/undefined/수치/BigInt/boolean/객체/함수/symbol/강제 변환·프록시 입력 23개입니다. 각 입력을 초기 상태, 성공 밀기 후 history가 있는 상태, 완료 상태에서 검사하며 객체 동일성·전체 스냅샷·boxes/history 참조·moves/pushes 보존을 단언합니다. 추가 블록을 제거하면 원래 단위시험 파일과 바이트 동일함을 확인했습니다. 기존 단언을 변경하거나 약화하지 않았습니다.

추가 코드에 네트워크·저장·셸 실행·자격 증명·eval 변경은 없습니다. 실제 HTTP의 기존 엄격 CSP는 그대로였으며, 생산 소스 변경은 위 가드 한 줄뿐입니다.
