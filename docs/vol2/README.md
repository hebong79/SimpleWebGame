# 두 번째 스무 가지 작은 쉼표 · 21~40

사용자 제공 기획·화면 시안을 참고해 기존 게임 서재에 추가하는 한국어 브라우저 게임입니다. 실행은 프로젝트 루트에서 `npm start -- --port 3182`, 주소 `http://127.0.0.1:3182/`입니다. 홈의 **새로 도착한 스무 가지 쉼표**를 누르면 이번 게임 20종을 한 번에 볼 수 있습니다. 원래 20종과 준비 중 카드 29종도 유지합니다.

게임 영역에 초점을 두면 키보드를 사용할 수 있습니다. 실시간 게임은 탭·창을 벗어나면 자동 정지하며 재개를 눌러야 다시 진행합니다. 퍼즐의 실행 취소, 새 판 확인, 도움말·기록·음소거를 제공합니다. 저장 실패 때는 현재 화면에서 계속 플레이할 수 있습니다.

검증 재실행: `npm run test:vol2`. 타입검사·새 후보 빌드·기존/신규 단위·런처·구문 검사 후 실제HTTP의 PC Chromium·모바일 Chromium·모바일 WebKit에서 새20종과 홈 연결을 검사합니다. 기존 설치된 개발 도구를 사용하며 새 패키지를 설치하지 않습니다. 상세 결과는 `BUILD_*.md`, `QA_*.md` 및 `artifacts/g032-*`의 해당 실행 기록을 확인합니다.

운영 실행 검증은 최종 작업일지와 HANDOFF를 확인하세요. 사용자의 추가 지시로 별도 확인 질문 없이 단일 게임 앱15010에 반영합니다. Git 커밋·푸시는 수행하지 않습니다. 물리 모바일기기·사람의 체감 난이도/시간·실청취는 자동 브라우저 결과와 구분합니다.

`npm run test:vol2`는 미사용 후보 빌드용입니다. 운영 반영한 `g032-build`는 `RELEASE_LOCK.json`으로 덮어쓰기를 차단합니다. 후속 변경은 `node scripts/build.mjs --out-dir artifacts/<새이름>`으로 새 후보를 만들고 검증해야 합니다. 현재 운영본 기본 흐름 재확인은 `node scripts/vol2-smoke.mjs --live`, 현재 소스 규칙 검사는 `npm run test:games`를 사용합니다.
