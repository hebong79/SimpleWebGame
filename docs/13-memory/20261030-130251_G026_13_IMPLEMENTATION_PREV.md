## 실제 API (QA/통합용)
### engine.mjs exports
- constants: `SNACKS`, `MODES` (`easy:{columns:3,pairs:6}`, `normal:{columns:4,pairs:8}`), `MAX_ATTEMPTS=999999`, `MAX_ELAPSED_MS=86400000`, `MISMATCH_MS=800`.
- `createReady(mode='normal', roundId=0)` → 준비 상태. 잘못된 옵션은 throw.
- `createDeck(mode, rng=Math.random)` → `{index,id,revealed:false,matched:false}[]`. 잘못된 RNG 반환/예외는 throw; 기존 상태를 수정하지 않습니다.
- `startRound(state, rng=Math.random)` → deck 생성 성공 뒤에만 `roundId+1`, phase playing. 실패는 원상태 유지/throw입니다.
- `reveal(state,index)`, `advance(state,dt)`, `pause(state,cause='manual')`, `resume(state)` → 새 상태 또는 무효 입력 시 **동일 상태 객체**. `dt`는 primitive finite 0..250ms, 0은 no-op입니다. index는 primitive 정수입니다.
- phase 값: `ready | playing | paused | success | limit`. `dialog`는 엔진 phase가 아니라 UI snapshot 별도 필드입니다.
- state: `mode,roundId,phase,pauseCause,cards,firstIndex,mismatchIndices,mismatchRemainingMs,attempts,matchedPairs,activeElapsedMs,firstFlipStarted`.

### save.mjs exports
- `STORAGE_KEY`, `THEMES`, `MAX_COMPLETIONS`, `defaults()`, `validModeRecord(value,mode)`, `parseSave(raw)`, `compareBest(candidate,best)`, `settleRecord(record,state)`, `createStore(getStorage?)`.
- `parseSave` → `{data,warning}`. `compareBest` → `new | tie | kept`.
- `settleRecord` → `{record,comparison}` (`comparison:null`이면 비성공/무효). 정산 1회 소유권은 아래 store가 보장합니다.
- store API: `snapshot()` deep clone, `warning()` boolean, `applySettings(patch)` changed boolean, `settle(state)` comparison 또는 중복/무효일 때 null.
- 정확한 저장 key: `simplegames.snack-pairs.v1`.
```json
{"version":1,"settings":{"mode":"normal","theme":"cream","muted":true},"modes":{"easy":{"completions":0,"best":null},"normal":{"completions":0,"best":null}}}
```
- 성공 best: `{attempts:<pairs..999999>,elapsedMs:<1..86400000 integer>}`. completions 0..1000000, best null iff completions 0. unknown 속성 무시, 각 mode 독립 복구입니다. 진행 중 deck은 저장하지 않습니다.

### Read-only browser snapshot
- `window.__g026Snapshot()`만 제공하고 setter/autosolve는 없습니다. 반환 전체를 `structuredClone`하며 함수 property도 non-writable/non-configurable입니다.
- shape: `{gameId:'snack-pairs', ...engineState, round:roundId, dialog:null|{kind,pending}, stats:{attempts,matchedPairs}, timing:{activeElapsedMs,mismatchRemainingMs,firstFlipStarted}, settings:{mode,theme,muted}, record:{easy,normal}, storageWarning, comparison}`.
- `cards[index].id`는 자동화의 **읽기 관찰용**으로 닫힌 카드에도 있습니다. 닫힌 카드 DOM accessible label/이미지에는 간식 ID/이름을 노출하지 않습니다.
- dialog kind: `help | theme | mode | modeConfirm | restart | home`. 열려 있는 동안 엔진은 paused 또는 ready/result입니다.
- 정상 입력 selectors: `#primary` (시작/일시정지/재개/다시 도전), `#restart`, `#mode`, `#theme`, `#help`, `#mute`, `#home`, `#board .card[data-index="0"]` 등 0-based 카드.
- modal: `#dialog`, `#dialog-cancel`, `#dialog-apply`, `[data-choice="easy|normal|cream|meadow|evening"]` role radio. mode가 active이면 Apply 뒤 `modeConfirm`에서 두 번째 확인이 필요합니다. 취소/닫기는 자동 재개하지 않습니다.
- 상태/기록 DOM: `#status`, `#pairs`, `#attempts`, `#time`, `#record-best`, `#record-count`, `#storage-warning`.
