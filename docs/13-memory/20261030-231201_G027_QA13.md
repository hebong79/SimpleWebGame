### 하네스/도구 관찰 (제품 결함 아님)
- WebKit `fullPage` 스크린샷은 CSP `style-src`가 거부하는 스타일시트를 주입해 콘솔 error를 냅니다. 스크린샷 호출 중에만 `tool-noise-*.json`으로 분리 기록했고 그 외 시간의 콘솔은 0건을 단언했습니다(WebKit 스크린샷 한계).
- Playwright WebKit 빌드에는 `AudioContext`가 없어 WebKit에서 실제 소리/오디오 생성 검증을 못 했습니다(게임은 무음 폴백, 오류 없음). 이 빌드는 WebKit에서 터치 누름 유지(80ms)도 제공하지 않아 마우스 80ms 누름으로 대체했습니다.
- Chromium(Windows)에서 마우스 가운데 버튼은 자동 스크롤로 다음 클릭을 삼킵니다. 터치 드래그/스와이프 직후 첫 탭은 브라우저가 click을 내지 않습니다(윈도우 캡처 리스너로 확인, `debug-tap-after-cancel.json`). 두 경우 모두 게임이 아닌 브라우저 동작이라 테스트에서 제외/1회 재시도로 처리했습니다. `Input.synthesizeScrollGesture`는 이 에뮬레이션에서 스크롤하지 않아 수동 CDP 스와이프로 대체했습니다.
- 진짜 포커스 변경으로 `blur`가 발생하는지는 새 페이지 `bringToFront`로 시도했으나 이벤트가 0건이었습니다(헤드리스 한계). blur/visibility/pagehide는 이벤트를 합성해 검증했습니다.
