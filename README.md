## G-014 · 스네이크와 퐁 추가

기존 게임 서재에 **꼬마 용 간식 여행(스네이크)**과 **네온 랠리(퐁)**를 통합했습니다. 목록은 총 32개, 플레이 가능 3개, 준비 중 29개입니다. 검색·장르·즐겨찾기·정렬은 공통으로 사용하고 각 카드는 자기 게임 페이지를 엽니다.

```sh
node scripts/build.mjs --out-dir artifacts/g014-build
node artifacts/g014-build/src/server/index.js --port 3105
```

통합본: http://127.0.0.1:3105/ . 일반 빌드/실행은 기존처럼 npm run build 및 npm start입니다. 이번 검증은 기존 dist와 실행 중인 3101/3104 서버를 교체하지 않습니다.

- 2048: /game.html
- 스네이크: /games/02-snake/index.html
- 퐁: /games/03-pong/index.html

스네이크·퐁은 준비 화면에서 시작 버튼으로 플레이합니다. 게임 내 작은 쉼표 링크로 공통 목록으로 돌아옵니다. 기록은 게임별 별도 localStorage 키를 사용하며 원본 4173 주소의 기록은 다른 포트로 자동 이전되지 않습니다. 기존 2048 저장 키와 즐겨찾기 ID는 유지합니다.

새 게임 엔진 검사: npm run test:games. 전체 테스트 명령과 실제 통합 검증 결과·제한은 docs/G014_INTEGRATION.md와 최신 docs/HANDOFF.md를 참조하세요. 아래 G-013 및 초기 MVP 기록은 당시 범위의 이력입니다.


PC 방향키와 모바일 스와이프를 지원하는 독립형 1인용 웹 퍼즐입니다. 4×4 판에서 같은 숫자를 합쳐 2048을 만들고, 더 큰 타일에 도전하거나 정원을 해금합니다.

## 승인 시안 통합본 (G-013)

실제 홈에서 검색·장르·즐겨찾기·정렬·더보기를 사용하고 숫자 정원의 게임 시작을 누르면 별도 게임 페이지에서 바로 플레이합니다. 현재 플레이 가능한 게임은 2048 한 종류이고 다른 29개 카드는 개발 예정입니다. 게임에는 일시정지·이어서하기·다시시작·게임종료와 실제 결과·홈 이동을 제공합니다.

기존 실행 서버와 빌드를 유지하기 위해 통합본은 별도 폴더로 검증합니다.

```sh
node scripts/build.mjs --out-dir artifacts/g013-build
node artifacts/g013-build/src/server/index.js --port 3104
```

브라우저 주소는 http://127.0.0.1:3104/ 입니다. 홈에서는 게임이 시작되지 않으며 게임 선택·게임 주소 직접 접속·게임 페이지 새로고침마다 새 판을 한 번 시작합니다. 최고기록·정원·소리 설정은 같은 브라우저와 주소에서 유지됩니다. 진행 중인 보드는 저장하지 않습니다.

기본 `npm run build` 출력은 계속 dist입니다. 기존 dist의 3101 실행과 시안의 3102 주소는 통합본 3104와 별개입니다. 이번 작업은 기존 PM2 서버나 공개 배포를 자동 교체하지 않습니다.

## 빠른 실행

**Node.js 24 이상**이 필요합니다. 이미 `dist/` 빌드 파일이 있으면 npm 설치 없이 실행할 수 있습니다.

```sh
node dist/src/server/index.js
```

브라우저에서 `http://127.0.0.1:3101`을 여세요. Windows에서는 `start-game.cmd`를 더블클릭하셔도 됩니다. 종료는 실행 창에서 Ctrl+C입니다. 기본값은 로컬 PC에서만 접근하는 loopback입니다.

### 소스에서 설치·개발

```sh
npm ci
npm run build
npm start
```

첫 개발용 패키지 설치에는 인터넷이 필요합니다. 빌드 후 게임 실행에는 npm 패키지, 인터넷, 계정, DB, 다른 게임 폴더가 필요하지 않습니다. `dist/public/`은 별도 정적 웹서버에 올려 사용할 수 있습니다. 임의 `file://` 직접 열기와 서버를 끈 상태의 첫 접속/PWA는 지원 범위가 아닙니다.

```sh
npm run dev
npm start -- --port 3201
```

### 휴대폰에서 접속하기

모바일 화면·입력을 구현했습니다. 같은 Wi-Fi의 실제 휴대폰 접속을 원하실 때만 다음 명령으로 **LAN 공개를 직접 선택**하세요.

```sh
npm start -- --host 0.0.0.0
```

휴대폰 주소는 `http://<PC의 내부 IPv4>:3101`입니다. 휴대폰에서 `127.0.0.1`은 PC가 아니라 휴대폰 자신을 가리킵니다. 방화벽 허용이 필요할 수 있습니다. 공유기 포트포워딩/인터넷 공개는 하지 마세요. 이번 검증에서는 loopback만 실행했고 LAN/실물 Android·iPhone 테스트는 하지 않았습니다.

## 조작과 진행

- **PC:** 시작 후 보드를 클릭하거나 Tab으로 초점을 맞춘 뒤 방향키. 길게 누르기는 1회만 처리합니다. Esc는 일시정지입니다.
- **모바일:** 보드 위에서 한 손가락으로 상하좌우 **24 CSS px 이상** 밀어주세요. 보드 밖은 일반 페이지 스크롤입니다. 대각선 동률/다중 터치는 이동하지 않습니다.
- 실제 이동에만 새 타일이 1개 생성됩니다. 2는 90%, 4는 10%입니다. 한 입력에서 같은 타일이 연쇄로 다시 합쳐지지 않습니다.
- 합쳐진 숫자만큼 득점합니다. 2048 축하 후 계속할 수 있으며, 이동할 수 없으면 종료입니다.
- 일시정지 버튼으로 멈추면 **이어서하기**, Esc·탭/창 이탈 보호 정지에서는 **게임 재개**를 눌러주세요.
- 새로 시작은 현재 판만 초기화합니다. 도움말/기록·정원/음소거는 게임 안에서 조작합니다.
- 정원은 기본 **씨앗 뜰**, 최고 타일 **256 → 초록 숲**, **1024 → 꽃 정원**의 3종입니다. 외형은 규칙을 바꾸지 않습니다.

## 기록과 데이터

`localStorage`의 `number-garden:profile:v1` 키에 최고 점수/타일, 시작·종료·달성 횟수, 누적 이동·획득점수, 정원, 음소거를 저장합니다. **진행 중인 보드는 저장하지 않습니다.** 게임 페이지 새로고침은 새 판이며 기록은 유지됩니다. 홈 즐겨찾기는 `simplegames.library.favorites.v1` 키로 별도 저장합니다.

손상·구버전 값은 검증 후 복구하고 안내합니다. 저장이 차단되면 경고와 함께 메모리 플레이를 유지합니다. 브라우저 데이터 삭제/시크릿모드 종료/다른 포트·브라우저에서는 기록이 유지 또는 공유되지 않을 수 있습니다. 여러 탭의 동시 기록 병합은 보장하지 않습니다.

SQLite는 이번 버전에 사용하지 않았습니다. 서버 계정/온라인 기록이 없는 개인용 게임으로 불필요한 DB 의존성을 만들지 않기 위한 결정입니다.
