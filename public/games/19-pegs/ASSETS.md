# 조약돌 하나 (19-pegs) 자산 출처와 라이선스

- 모든 시각 요소(돌, 구멍, 판, 선택·후보·제거 예정 표시, 3개 테마)는 이 프로젝트에서 직접 만든 CSS(`radial-gradient`, `box-shadow`, `border`)와 유니코드 기호(● ○ ◉ ◎ ✕)이다. 이미지, SVG 파일, 웹폰트, CDN은 없다.
- 소리는 `audio.mjs`의 WebAudio 합성(사인·사각·삼각파 몇 음)이다. 오디오 파일은 없으며 기본 꺼짐이다.
- 단계 배치(10개)는 `artifacts/g030-design19/`의 설계 검증 스크립트가 시드 20261102로 생성했고 독립 solver로 풀이 가능함을 확인한 이 프로젝트 자체 데이터이다.
- Simon Tatham의 Pegs 코드·이미지는 복제하지 않았다. 규칙(상하좌우로 한 칸 건너 점프해 돌을 제거)만 참고했다.
- 기존 프로젝트 파일 재사용: 없음(17-flip, 18-samegame의 구조와 코드 스타일만 참고했고 파일은 복사하지 않았다).
- 라이선스: 위 자체 제작물은 프로젝트 소유이며 외부 라이선스 의무가 없다.
