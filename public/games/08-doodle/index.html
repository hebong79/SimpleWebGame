구름 사이, 작은 도약

토끼는 구름 발판에 내려앉을 때마다 자동으로 뜁니다. 상승할 때는 발판을 통과하고, 내려올 때 발이 겹쳐야 다시 뛸 수 있어요.

  • 경기장을 누르거나 Tab으로 초점을 둔 뒤 ← → 또는 A D를 누르세요. 반대 방향을 함께 누르면 마지막으로 누른 쪽이 우선합니다.
  • 화면 좌우 절반 또는 방향 버튼을 누르는 동안 이동합니다. 놓거나 취소하면 멈춥니다. 두 손가락을 대면 안전하게 정지합니다.
  • Space: 명시 시작/재개 · P 또는 Esc: 정지. 화면을 떠나거나 지연이 길면 보호 정지하며 직접 재개해야 합니다.
  • 최고 상승 높이 10px당 1점. 한 판 500점 뒤 생성되는 일부 발판은 천천히 좌우로 움직입니다.
  • 완료 최고 100점: 별빛 / 500점: 당근 / 완료 누적 2000점: 탐험가. 잠긴 옷은 미리보기만 가능합니다.
  • 재시작과 홈 이동은 진행 판을 중도 종료로 한 번 정산합니다. 취소하면 정지 상태를 유지합니다. 새로고침 시 진행 판은 복원하지 않습니다.
