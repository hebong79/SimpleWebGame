# CW2-VERIFY — 후속 요청 수신 확인

이 요청은 대현자 PM이 별도 워커 cody-02의 동일 세션 재개를 검증하기 위해 전달합니다. 실제 게임 개발 작업이 아닙니다.

셸·파일·MCP·웹·서브에이전트 등 어떤 도구도 사용하지 마세요. 파일이나 설정을 변경하지 마세요. 작업 완료 보고서 파일도 만들지 말고, 응답 본문만 반환하세요.

이전 연결 시험 대화에 근거하여 아래 항목을 JSON 한 개로 응답하세요.
- worker_id: 본인의 관리용 워커 ID
- pm: PM 이름
- previous_challenge: 직전 연결 시험에서 받은 challenge 문자열. 기록에 없으면 추측하지 말고 null
- status: ready
- tools_used: false

이 요청에는 이전 challenge 값을 제공하지 않았습니다. 이전 대화 내용에 근거하여 회신해야 합니다.
